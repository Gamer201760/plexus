# Использование ИИ

ИИ использовался для исследования, разработки, проверки кода и подготовки материалов.
В приложении агент отвечает на вопросы о данных, управляет картой и вызывает расчётные
инструменты. Значения индекса возвращает код модели; агент не должен выдумывать числа.

Реальные идентификаторы регионов, пунктов и дорог получаются через API. Результат содержит
исходные допущения и статус выполнения. Для денежной оценки нужны заданные поток поездок
и стоимость часа. Ответ языковой модели сам по себе не служит доказательством.

Проверки: модульные тесты, сравнение быстрого обновления расстояний с полным графом,
API и интерфейс. [Метод](road-analysis.md), [инструменты чата](chat.md).
