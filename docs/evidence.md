## Скорость дорожного слоя, 10 ноября 2026

На фиксированном окне Владимирской области полный HTTP-ответ с gzip сократился
с 7,25 с (один контрольный запуск) до 0,57–0,81 с (три запуска).
Все 64 779 исходных геометрических рёбер этого окна присутствуют в новом ответе;
набор из 29 765 OSM way совпадает. Это замер API, не FPS браузера.
[Числа и область проверки](results/road-render-performance.json),
[метод, запуск и ограничения](clickhouse.md).


## Рабочее хранилище

**Измерено, 10.11.2026:** рабочий API запускается из ClickHouse без исходных DuckDB,
Parquet и JSON. Сверены все узлы и рёбра, региональная матрица, ответы API и повторный
расчёт; подробности и границы проверки — в [описании хранилища](clickhouse.md).
Backend:157unit+40интеграционных тестов; frontend:393теста и сборка.
Контейнер backend загрузил реальные данные без установленного модуля DuckDB.
