# Что проверено и чего проверки не доказывают

> Результаты отделены от источников и допущений. Численный контроль не заменяет проверку действующего транспорта.

**Читайте, если** оцениваете доказательства

## Какие утверждения имеют проверку?

| Утверждение | Статус | Доказательство и предел |
| --- | --- | --- |
| Частота 4 не меняет лучшее время; 7 даёт 14,243 ч | Измерено | [Протокол пилота](results/pilot-validation.json); условная сеть, не наблюдение поездки |
| Два алгоритма согласны по времени и статусу | Измерено | 24 сочетания: два сезона × четыре варианта × три пары; тот же граф |
| Исходный артефакт не меняется запросами | Закреплено | `backend/tests/unit/controller/test_pilot_routes.py`, тесты use case |
| Неизвестная частота не превращается в нулевое ожидание | Закреплено | Доменные тесты пилота и предупреждения об альтернативах |
| Частотное ожидание без суточного ограничения | Закреплено | `backend/tests/unit/domain/test_pilot.py`, контроль 84/42/28 ч |
| Сжатый граф сохраняет контрольные сезонные пути и отключение | Закреплено | `tests/test_transport_model.py`; малый синтетический граф, не весь национальный PBF |
| На выбранных 133 OSM-путях не найден явный запрет access/vehicle/motor_vehicle/motorcar | Измерено | [Аудит тегов](results/pilot-road-tag-audit.json); отсутствие запрета не доказывает проходимость |
| API проходит целевой p95 ≤ 2 с локально | Измерено | [200 HTTP-запросов](results/pilot-http-benchmark.json); последовательный localhost после прогрева |
| Путь карта → пилот → расчёт → экспорт → сброс работает | Проверено вручную | Также закреплён [Playwright](../frontend/e2e/pilot-experiment.spec.ts), desktop 1440×900 |
| Национальная база нормирована, добавление связей не ухудшает Hansen | Измерено | [777060 строк и 12 выборочных формул](results/national-validation.json); внутренняя проверка модели |
| Рейтинг зависит от состава рынков | Измерено | [Исключение крупнейшего рынка](results/target-coverage-sensitivity.json), 82 региона × 5 сценариев |
| Историческая частота два рейса в неделю | Из источника | [Происхождение](pilot-sources.md); публикация марта 2025, не расписание на дату демонстрации |

| Приложение оценивает ВРП или медицинскую доступность | Неверно, и это сказано | Таких входов и модели эффекта нет |

## Как повторить численный контроль пилота?

Гипотеза: производственный Dijkstra и независимый Floyd–Warshall совпадают по времени и достижимости.

Команда: `PYTHONPATH=backend/src uv run python etl/validate_pilot.py`.

Выборка: 24 результата на поставляемом графе; отчёт также содержит повторяемость и 200 измерений внутрипроцессного расчёта.

Предел: оба алгоритма используют одинаковые исходные рёбра и допущения, поэтому согласие не подтверждает их соответствие реальному сообщению.

## Какие отрицательные результаты сохранены?

Частота четыре не даёт выигрыша. Отключение местной связи оставляет Сыстыг-Хем без пути в рассматриваемой сети. Для Тоора-Хема неизвестная авиационная частота ограничивает вывод об оптимуме. Лето и зима не измеряют межсезонные закрытия.

Национальные проверки и чувствительность описаны [отдельно](indices.md); их нельзя использовать как подтверждение точности поездки конкретного жителя.
