# Где заканчивается вывод модели

> Plexus сравнивает варианты при зафиксированных данных и допущениях.
> Действующее сообщение, стоимость и экономический эффект требуют отдельных наблюдений.

**Читайте, если** используете результат для решения · **Связано:** [Метод пилота](pilot-method.md)

---

| Ограничение | Статус | Как учитывать |
| --- | --- | --- |
| Текущая работа исторических авиационных и водных линий не установлена | Неверно, и это сказано | Проверить расписание и право поездки у перевозчика |
| Отсутствие OSM-тега закрытия не доказывает проходимость дороги | Допущение, не результат | Сверить выбранный путь с наблюдениями; не считать его гарантированным |
| Ожидание `84/f` предполагает равные интервалы и случайную потребность | Допущение, не результат | Сравнивать базу и варианты одной моделью; смотреть вариант без ожидания |
| Независимые ожидания не учитывают согласованные пересадки | Допущение, не результат | Для точной поездки нужны расписания всей цепочки |
| Неизвестные частоты иногда заменены помеченным допущением | Допущение, не результат | Смотреть источники, JSON и предупреждение о возможных альтернативах |
| Лето/зима не измеряют межсезонное закрытие | Неверно, и это сказано | Нужны даты фактического открытия и закрытия |
| Национальная нормировка относится к 82 регионам и населению входного снимка | Измерено | Не распространять её на всё население России |
| Состав 180 рынков влияет на рейтинг; исключение Москвы снижает оценку Московской области на 66,6% | Измерено | [Стресс-тест покрытия целей](results/target-coverage-sensitivity.json); не переносить результат на произвольный набор рынков |
| Национальный дорожный поиск неориентированный | Допущение, не результат | Направления дорог симметризуются минимальным весом; городские односторонки упрощены |
| Сельская дорожная доступность и время до центра не подтверждают доступ к больнице | Неверно, и это сказано | Конкретные услуги и объекты не моделируются |
| ВРП, потоки, окупаемость и стоимость вариантов не оценены | Неверно, и это сказано | Не объявлять инвестиционный приоритет по одному времени |
| Контрольные примеры и независимый алгоритм не являются полевой валидацией | Неверно, и это сказано | Проверять граф и наблюдения отдельно от математики |
| Живая репетиция речи и отправка через форму не подтверждаются кодом | Неверно, и это сказано | Нужны отдельные факты проведения и подтверждение формы |

Для Сыстыг-Хема отсутствие альтернативы означает отсутствие пути в рассматриваемой сети.
Для частоты четыре нулевой эффект сохранён. Эти отрицательные результаты входят в
[протокол пилота](results/pilot-validation.json).
