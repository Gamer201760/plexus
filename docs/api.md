# Какие данные возвращает API

> FastAPI читает зафиксированные экспорты и синхронно считает маленький пилот. Национальная база не изменяется пользовательским запросом.

**Читайте, если** подключаете интерфейс или повторяете запрос

---

## Где находится контракт?

[OpenAPI](../backend/openapi.json) — полный контракт; `/docs` доступен при локальном запуске backend. Типы интерфейса генерируются из него.

| Метод и путь `/api/v1` | Назначение | Параметры |
| --- | --- | --- |
| GET `/health` | Состояние сервиса | Нет; не доказывает наличие каждого экспорта |
| GET `/regions` | Региональные показатели | `season=all/summer/winter`, `network_mode=road/multimodal` |
| GET `/regions/{id}` | Карточка региона | Те же сезон и режим |
| GET `/regions/{id}/links` | Исходные ручные связи | Сезон, вид транспорта |
| GET `/regions/{id}/settlements` | Страница пунктов | Поиск, сортировка, limit/offset |
| GET `/links` | Связи с координатами | Не вычисляет маршруты национального графа |
| GET `/index` | Состояние подключённых индексов | Метаданные компонентов |
| GET `/pilots` | Список пилотов | Размер и версии |
| GET `/pilots/{id}` | Полные входы пилота | Пары, рёбра, источники, допущения |
| POST `/pilots/{id}/evaluate` | База и изменённый вариант | Сезон, версии, changes |
| GET `/scenarios` | Каталог сценария индекса | 180 городов-рынков, версии матриц |
| POST `/scenarios/evaluate` | Пересчёт индекса с новыми связями | Сценарий road/summer/winter, версии, links (до 5); концы связи: опорный город или ОКТМО населённого пункта |

## Как воспроизвести опыт?

Получите `/api/v1/pilots/tuva`, сохраните `model_version` и `artifact_version`. Отправьте их вместе с сезоном `summer` или `winter` и массивом `changes`. Каждый элемент содержит `edge_id`, необязательные `enabled` и `frequency_per_week`. Идентификатор берётся из полученного пилота, а не из названия линии.

Ответ содержит исходные и изменённые поездки, суммы движения и ожидания, рёбра маршрута, разницу, статусы и допущения. `null` не заменяется нулём. Ограничение частоты 1–28 относится к вводу первой версии; исходное значение за границей сохраняется, но не редактируется.

## Как различать ошибки и результаты?

| Код/статус | Смысл |
| --- | --- |
| 404 | Неизвестный регион, пилот или ресурс |
| 409 | Версия опыта устарела; загрузить входы заново |
| 422 | Некорректный сезон, частота, связь или повтор изменения |
| 503 | Не хватает входов либо артефакт повреждён |
| `no_route` | Успешный поиск без пути в рассматриваемой сети |
| `incomplete_alternatives` | Найден путь, но оптимальность ограничена неизвестными частотами |

Чтение кэшируется в процессе. Для замены экспортов нужен перезапуск backend. Запросы не записывают национальные данные и не обращаются к платным моделям.

## Ставропольский край: актуализация 8 ноября 2026

В существующие связи региона `07000000` добавлены 653 межрегиональных автобусных маршрута (`mode=bus`) из реестра Минтранса на 20.10.2026. Концы маршрута взяты из прямого расписания; координаты остановок неизвестны, поэтому линии на карте не рисуются. Частота не преобразована в рейсы за неделю и не подменяется допущением. `season=all` установлен только для 601 маршрута, у которого все строки прямого расписания имеют период «круглогодично»; остальные 52 имеют неизвестный сезон и видны при выборе всех сезонов.

В `/sources` добавлены четыре источника со скачиваемыми архивами OSM, расписаний, ОМС и исторических дорожных справок. Архивы обслуживаются фронтендом по `/datasets/stavropol-*.zip`, содержат подготовленные данные и описание первичных источников. OSM не превращён в маршрутизируемый граф, адреса помощи не геокодированы, индексы не пересчитывались. Экономические показатели и население совпадают с новым региональным срезом. Обновление: `python3 scripts/refresh_stavropol.py /path/to/source/workspace`.

Национальные индексы импортированы из feat/model-validation и относятся к её зафиксированному набору входов. Локальные автобусные маршруты добавлены к каталогу, но ещё не включены в этот расчёт.
