# Геометрия карты

`GET /api/v1/geo/regions` возвращает `view_box`, список `regions` и регионы без геометрии в `missing`. У региона есть `id`, `name`, исходный SVG-контур `path` и необязательный облегчённый контур `path_low`. Если файл облегчённых контуров отсутствует, API возвращает `path_low: null`, фронтенд использует `path`.

Оба контура используют координаты исходной проекции и `view_box: "0 0 1000 620"`. На общей карте при масштабе до 2 включительно используется `path_low`, выше 2 используется `path`. Переключение происходит после завершения жеста. Карта отдельного региона и расчёты продолжают использовать исходные данные.

Экспорт из корня репозитория:

```bash
node frontend/atlas/scripts/prepare-map-detail.mjs
```

Команда читает `frontend/atlas/public/geo/region-paths.json` и пишет соседний `region-paths-low.json`. Используется mapshaper 0.7.101 с Douglas–Peucker, planar, interval=0.3 и keep-shapes; координаты округляются до 0.1. Первый запуск требует npm и сети для загрузки инструмента. Готовый экспорт хранится в репозитории, приложению сеть для упрощения не нужна. После изменения исходных контуров нужно повторить экспорт и перезапустить API, который кеширует прочитанные данные.

Экспорт 8 ноября 2026 года сохранил все 83 идентификатора геометрии. Число сегментов `L` снизилось с 92 840 до 19 689, размер отдельного JSON с облегчённой геометрией составил 233 127 байт. Метод и SHA-256 исходного файла записаны в экспорте. Это дополнительные данные API, поэтому размер ответа вырос; выигрыш относится к отрисовке. При упрощении свернулись 314 мелких колец; инструмент сообщил о 15 неисправленных пересечениях. Геометрия служит подложкой, не кадастровой границей. Известный шов у 180-го меридиана этим изменением не исправляется.

Полная схема всех маршрутов: `/openapi.json`, интерактивная документация: `/docs` на порту API.

## Ставропольский край: актуализация 8 ноября 2026

В существующие связи региона `07000000` добавлены 653 межрегиональных автобусных маршрута (`mode=bus`) из реестра Минтранса на 20.10.2026. Концы маршрута взяты из прямого расписания; координаты остановок неизвестны, поэтому линии на карте не рисуются. Частота не преобразована в рейсы за неделю и не подменяется допущением. `season=all` установлен только для 601 маршрута, у которого все строки прямого расписания имеют период «круглогодично»; остальные 52 имеют неизвестный сезон и видны при выборе всех сезонов.

В `/sources` добавлены четыре источника со скачиваемыми архивами OSM, расписаний, ОМС и исторических дорожных справок. Архивы обслуживаются фронтендом по `/datasets/stavropol-*.zip`, содержат подготовленные данные и описание первичных источников. OSM не превращён в маршрутизируемый граф, адреса помощи не геокодированы, индексы не пересчитывались. Экономические показатели и население совпадают с новым региональным срезом. Обновление: `python3 scripts/refresh_stavropol.py /path/to/source/workspace`.
