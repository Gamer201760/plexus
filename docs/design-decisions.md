# Проектные решения

Правила, которые не видны из кода: комментариев в коде нет, поэтому неочевидное объясняется здесь.

## Данные и API

| Решение | Какой сбой предотвращает | Чем закреплено | Предел |
| --- | --- | --- | --- |
| Бэкенд только читает выгрузку атласа из `DATA_DIR` (по умолчанию `frontend/atlas/public`) и не копирует 55 МБ данных | Две расходящиеся копии одних и тех же CSV и JSON | `tests/unit/composition/test_settings.py` | В Docker каталог нужно смонтировать, иначе эндпоинты данных отвечают 503 `data_unavailable` |
| Координаты пунктов проецируются той же коническей проекцией, что и контуры регионов (`domain/projection.py` повторяет `frontend/atlas/scripts/prepare-regions.py`) | Точки и связи на карте региона оказываются вне его контура | `tests/unit/domain/test_projection.py`: начало координат, переход через 180-й меридиан, вписывание рамки в холст | Крыма нет в подложке 2013 года, у него `has_geometry: false` |
| Неизвестное значение передаётся как `null`, а не 0 | Ноль и «нет данных» неразличимы в таблицах и на карте | Схемы `controller/atlas/schemas.py`, во фронтенде `NoValue` | Число компаний в населённом пункте может быть настоящим нулём |
| Сезон «Все» считает и связи без сезона, «Лето» и «Зима» включают круглогодичные | Летом и зимой пропадают круглогодичные авиарейсы | `domain/transport.py`, `runs_in_season` | Связи без сезона видны только в режиме «Все» |
| В `controller/atlas/responses.py` тип `Responses` содержит `Any` | FastAPI принимает в `responses` словарь с произвольными значениями, точный тип не совпадает с его сигнатурой | mypy | Исключение ограничено одним псевдонимом типа |
| Индекс Хансена показывается как «не подключён», пока `indices.json` пуст | Карта выдаёт исходные данные за рассчитанный индекс | `/api/v1/index` отвечает `status: missing` | Нужна выгрузка `scripts/export-indices.py` из DuckDB |

## Интерфейс

| Решение | Какой сбой предотвращает | Чем закреплено | Предел |
| --- | --- | --- | --- |
| Один язык (русский) и одна светлая тема | Половина строк без перевода, недопроверенная тёмная палитра | Правило `single-theme`, тест словарей | Возврат второй темы потребует семантического слоя заново |
| Кольца знака используются в интерфейсе только как изолинии времени или в фирменных моментах | Знак превращается в декор и теряет смысл | Раздел «Изолинии» в дизайн-системе (`work/design/design-system.html`) | Правило не проверяется скриптом |
| Выделенный регион получает одну статичную обводку. Волны удалены | Анимация нескольких сложных контуров задерживала взаимодействие | `map-painter.ts`, проверка выбранного региона | Декоративного эффекта при выборе больше нет |
| Камера обновляется максимум раз за requestAnimationFrame; состояние React фиксируется после отпускания или 180 мс без колеса. Перелёт длится 260 мс и прерывается из текущей позиции | Ввод запускал повторные рендеры и длинные непрерываемые перелёты | `use-map-camera.ts`, `map-interaction.spec.ts` | Клавиатурный зум и reduced motion работают без перелёта |
| Контуры вне окна скрываются, во время движения используется `path_low`. Подсветка находится в отдельном SVG; попадание проверяется по кэшированному Path2D | Наведение вовлекало сложную SVG-геометрию в браузерную проверку попадания и перерисовку | `map-painter.ts`, нагрузочные измерения | Точное попадание использует исходную границу, упрощённая граница может визуально отличаться на несколько пикселей |
| Материковая часть для фокуса определяется по площади крупнейшего полигона из исходного контура. Выбор не зависит от запаздывающего ответа карточки региона | Острова Архангельской области сдвигали центр камеры, предыдущая карточка могла запустить неверный перелёт | `map-shapes.test.ts`, `map-regression.spec.ts` | Географические координаты островов сохранены; для островного региона фокусируется крупнейший остров |
| Перетаскивание разрешено при масштабе 1; ограничитель оставляет не меньше 15% рамки карты в окне | На исходном масштабе обе границы ограничения совпадали и блокировали сдвиг | `map-gesture.test.ts`, браузерная проверка перетаскивания сразу после открытия | Это ограничение рамки, а не фактической площади суши |
| Регионы на карте не получают фокус с клавиатуры; выбор с клавиатуры идёт через поиск, рейтинг и список регионов | 83 лишние остановки табуляции | `// biome-ignore` с причиной в `russia-map.tsx` | Карта без мыши служит иллюстрацией |
| Знак хранится как контуры (`docs/brand/*.svg`, `shared/ui/brand/mark-paths.ts`), кольца посчитаны смещением контура букв | Знак зависит от установленного шрифта | `work/brand/export_mark.py` | Изменение параметров знака требует повторного экспорта |
| Шкала карты: естественные разрывы (Fisher–Jenks) по логарифму значений, каждый порог округлён до самого круглого числа между классами, ноль отдельным классом | Квантили сливали Якутию (38 связей) и Красноярский край (115) в один цвет | `tests/features/map-explorer/scale.test.ts` | Пороги меняются вместе с данными |
| Показатель и сезон карты хранятся в адресе (`?metric=&season=&region=`) | Перезагрузка или ссылка теряет выбранный вид | `use-explorer-params.ts` | Значения по умолчанию в адрес не пишутся |
| Колесо обрабатывается нативным обработчиком с `passive: false`; масштаб зависит от величины и единиц delta. Горизонтальный свайп сдвигает карту, два указателя задают pinch | Зум карты одновременно увеличивал страницу, горизонтальное движение уменьшало масштаб | `map-gesture.ts`, модульные и браузерные тесты | Browser zoom доступен вне карты; Safari gesture events отменяются, физический Safari не проверен |
| Координаты курсора хранятся в ref, карточка двигается через transform. React получает только смену региона | Каждый пиксель движения пересчитывал панель и шкалу | `use-map-hover.ts`, memo для панели, легенды и тулбара | Во время жеста подсказка скрыта |
| Общий вид до масштаба 2 и любое движение используют `path_low`; после остановки на более крупном масштабе возвращается исходный `path`. Экспорт выполняется mapshaper, параметры описаны в `api.md` | Избыточная детализация нагружала растеризацию на общем виде | `prepare-map-detail.mjs`, тест охвата геометрии | Мелкие острова могут исчезать в общем виде; исходная геометрия остаётся доступной |
| Верхняя навигация переключает страницы без View Transition; остальные ссылки сохраняют прежнее поведение | Захват всего экрана задерживал частые переключения и блокировал взаимодействие | Браузерный тест быстрой навигации, замер кадров | Осознанное исключение из общего правила анимации переходов для часто используемых вкладок |
| Таблица регионов растёт вместе со страницей; внутри остаётся только горизонтальная прокрутка при нехватке ширины | Вертикальный скролл попадал то в таблицу, то в документ | Браузерный тест прокрутки из строки таблицы | Заголовок таблицы не закреплён относительно окна; 82 строки остаются в DOM |
