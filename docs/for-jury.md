# Как проверить приложение

Запустите backend с `GRAPH_DIR` и frontend по [инструкции](running.md).

1. Откройте карту и выберите любой регион из атласа.
2. Сравните индекс с другой территорией. Проверьте сезон и версию данных.
3. Откройте карточку региона, раздел «Сценарии», затем «Рассчитать изменения на карте».
4. Выберите дорогу и задайте изменение скорости или закрытие. Запустите расчёт.
5. Сравните индекс до и после, затронутые пункты и длительность.
6. Через чат задайте новую связь с явным временем проезда. Агент найдёт настоящие узлы.
7. Для денежной оценки укажите пару поездки, поток в год и стоимость часа.

Полный расчёт дороги занимает минуты. Одна новая связь использует подготовленные
расстояния, если они доступны для её концов. Нулевой эффект остаётся нулевым.
Без графа расчёт показывает ошибку недоступности. Чат требует серверной авторизации.
Лаборатория `/scenarios` отдельно требует матрицы `SCENARIO_DIR`.
[Метод и пределы проверки](road-analysis.md).
