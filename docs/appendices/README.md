# Исследовательские материалы к предложению

> Сохранены рабочие исследования данных, источников и гипотез. Их предварительные числа не подменяют проверенные результаты действующей модели.

**Читайте, если** проверяете материалы, созданные при исследовании

---

## Что относится к текущему выводу?

Текущий вывод и его пределы находятся в [методе пилота](../pilot-method.md), [национальной модели](../indices.md) и [реестре ИИ](../ai-register.md). Исследования ниже сохраняют историю гипотез, в том числе отвергнутых; утверждения о ВРП и трафике не стали результатом приложения.

| Материалы | Где читать | Как использовать |
| --- | --- | --- |
| Разведка семи табличных источников | [EDA](eda/README.md) | Периоды, пропуски, представительность; исходные CSV и скрипты рядом |
| Экономическая постановка | [Гипотезы](research/economic-connectivity.md) | Возможные будущие цели; не доказательство экономического эффекта |
| Трафик и грузовые данные | [Источники и ограничения](research/economic-traffic.md) | Не превращать транспортные средства в тонны без загрузки |
| Транспортные источники | [Перечень](research/transport-sources.md) | Проверять доступность, период и лицензии заново |
| Статистика | [Перечень](research/statistics-sources.md) | Проверять совместимость географии и периода |
| Политика и документы | [Источники](research/policy-sources.md) | Контекст задачи; не результат измерения |

Приложенные аналитические скрипты относятся к своему снимку и могут требовать внешних исходных файлов из `data/`. Они не нужны для запуска подготовленного сценария. Полный реестр скачанных наборов — [datasets](../../datasets/README.md).
