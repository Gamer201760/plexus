# Наблюдаемый трафик для экономической постановки

Проверено 2026-11-06. Короткий поиск по первичным источникам; цель — установить доступные измерения, а не выбрать окончательную модель или территорию. Общероссийская открытая OD-матрица грузовых/пассажирских потоков не подтверждена. Без такой матрицы нельзя выдавать региональные тонны организаций за объёмы отправления и прибытия каждой пары регионов.

Отдельная [официальная оговорка об учёте](https://russianhighways.ru/press/news/139155/) важна для калибровки: после соединения М-11 обходом Твери одна сквозная поездка стала учитываться системой платы один раз вместо прежних двух. ## 5. Что можно связывать в концепции и где остановиться

- **Наблюдаемый поток:** ТС/сутки в определённом сечении, отдельно легковые/грузовые при наличии классов. Не смешивать с автокм/год, тоннами/год организаций и числом зарегистрированных платных проездов.
- **Экономические возможности:** региональный ВРП, отраслевая структура, инвестиции или занятость могут задавать массу/ценность потенциальных возможностей. Это отдельный слой, не восстановленный фактический поток. Для отдельных городов нельзя распределять региональный ВРП без явно обозначенной модели.
- **Калибровка:** для сопоставления модельного OD с AADT нужна сеть и назначение OD-поездок маршрутам, а затем сумма проходящих через сечение потоков в тех же единицах/периодах. Несколько наблюдений на платных трассах не идентифицируют национальную OD-матрицу или уникальную модель спроса. Параметр притяжения/затухания, настроенный на этих точках, требует проверки на отложенных точках и периода учёта.
- **Критичность:** потеря доступности экономических возможностей при явно заданном ухудшении времени или отказе проверенного элемента может быть расчётным критерием. Для потерь фактического трафика нужны реальные потоки, альтернативные пути и правило переназначения. Из агрегата регионального тоннажа это не получается.
- **Связь с ВРП:** можно исследовать ассоциации и сценарные изменения доступности экономической массы. Нельзя превращать такой индекс или корреляцию в причинное обещание прироста ВВП/ВРП. Критический для резерва/эвакуации участок может иметь малый обычный поток; умножение критичности только на текущий трафик способно его скрыть.

Все формулировки о калибровке и критичности в последнем разделе — аналитические предложения для обсуждения, не утверждённая методология команды и не вывод из пресс-релизов операторов.
