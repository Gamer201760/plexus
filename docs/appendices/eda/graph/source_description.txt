0. О наборе данных
    ●​ В датасете собраны данные по региональным столицам и городам с
       численностью населения более 100 тысяч человек. Для каждой пары городов
       рассчитаны авто, ж/д и авиа расстояния в км и часах при наличии таких
       маршрутов.
    ●​ Для расчета автомобильных расстояний использовались OpenStreetMap и Open
       Source Routing Machine. Железнодорожные расстояния взяты из набора данных
       СберИндекса. Авиационные расстояния рассчитаны на основе данных
       OurAirports, Aviastats1 и Росавиации.
    ●​ Автомобильные расстояния могут быть занижены на извилистых маршрутах — в
       горной местности и на севере. Это связано с тем, что для экономии
       вычислительных ресурсов вместо точной длины дороги используется
       расстояние по прямой между узлами OSM.
    ●​ Время в пути во всех случаях рассчитано через среднюю скорость, а не по
       фактическим расписаниям, поэтому итоговые значения имеют погрешность
       около 11% (проверено на выборке пар по данным Яндекс.Карт,
       Яндекс.Расписаний и Flight Connections).

4. Известные ограничения
                                  Методология

Расчет автомобильных расстояний проводился в 3 этапа:

   1.​ На основе OSM PBF с Geofabrik собирался магистральный граф по России +
       Литва, Латвия и Эстония, для расчета маршрутов с Калининградом. Включались
       только дороги с тегами motorway, trunk, primary (в европейской части) и
       secondary (восточнее 60° в.д. и севернее 60° с.ш.), сезонные дороги
       исключались.
   2.​ С помощью OSMnx собраны локальные графы городов с радиусом равным
       расстоянию до ближайшей магистрали * 1,5 (но не более 400 км), чтобы
       рассчитать подъезд к магистралям.
   3.​ Далее с помощью алгоритма Дейкстры рассчитывались расстояния по
       маршруту: локальный подъезд A + магистральный граф + локальный подъезд B.​
       Для корректировки неточностей расчета для некоторых пар городов
       рассчитывалось расстояние с помощью OSRM (если расстояние < 400 км или
       расстояние более чем в 1,5 раза длиннее пути по прямой). Время в пути
       (distance_hr) рассчитывалось с использованием средней скорости 75 км/ч и
       прибавлялось дополнительные полчаса как поправка на более медленный
       выезд из города.

Для железнодорожных расстояний использовался датасет СберИндекса. Каждому
городу был присвоен territory_id в соответствии с тем центром какого
муниципалитета этот город является. Для Москвы, Санкт-Петербурга и Севастополя
выбраны муниципалитеты с главными вокзалами. Расстояния в км использованы как в
источнике, без изменений. Время в пути рассчитывалось с использованием средней
скорости 55 км/ч.

Авиационные расстояния рассчитывали по следующей схеме:

   1.​ Из данных OurAirports отобраны аэропорты, находящиеся в радиусе 75 км по
       прямой от центров городов (типы large, medium, small).
   2.​ Маршруты собирались из двух источников — Aviastats и Росавиация
       (субсидируемые маршруты на 2026 год). Aviastats — сервис для анализа данных
       авиационной отрасли России. Данные о фактических маршрутах на
       июнь-декабрь 2026 года были получены по запросу.​
       Если для пары городов было несколько вариантов маршрутов (через разные
       аэропорты), выбирались более близкие к центру городов аэропорты. Между
       выбранными аэропортами рассчитывалось расстояние по прямой (haversine).
   3.​ Расчет времени для большинства пар городов происходил с использованием
       средней скорости 840 км/ч + 45 минут на взлет и посадку. Часть данных
       Росавиации содержала тип воздушного судна. Для таких пар городов
       использовалась крейсерская скорость для соответствующего судна (средняя,
       если их несколько). Для пар городов с Калининградом к летному времени
       применялся коэффициент 1,5, чтобы учесть текущие удлиненные маршруты.

Набор данных содержит все возможные пары городов в обе стороны. Обратный
маршрут копирует оригинальный. В случае отсутствия маршрута атрибут
missing_reason содержит значение «Маршрут не найден».
                         Полнота и надежность данных

Ограничения источников данных и текущего алгоритма вычисления:

   1.​ При работе с OSM для экономии вычислительных ресурсов вместо точной
       длины дороги используется расстояние по прямой между узлами. Это может
       занижать длину извилистых дорог в горной местности и на севере.

   2.​ Почти во всех случаях время рассчитывалось с помощью средней скорости,
       поэтому итоговый показатель имеет погрешность в среднем в 11% (проверено
       вручную на выборке пар с помощью Яндекс.Карт, Яндекс.Расписания и Flight
       Connections).​

   3.​ При тестировании было обнаружено, что некоторые маршруты через аэропорт
       Минеральных вод не попали в источники, поэтому они были добавлены
       вручную (source == “manual”).


В наборе данных имеются следующие типы пропущенных значений:

   1.​ «Нет информации» ND (no data) — использовалось для атрибута source при
       отсутствии источника и маршрута для конкретной пары городов.
   2.​ «Неприменимо» CD (conflict data) — использовалось для атрибутов
       missing_reason когда маршрут присутствовал и в comment, когда комментарий
       не подразумевался.
   3.​ Атрибуты distance_km и distance_hr оставлены c пропусками в случае
       отсутствии маршрутов.
