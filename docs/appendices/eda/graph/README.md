# Исследование матрицы поездок между 180 городами

Скрипты читают исходный ZIP без изменения данных. Нужны Python 3, numpy и pandas; сеть не используется.

```bash
python3 work/eda/graph/analyze_graph.py --input-root datasets/intercity_connectivity --out work/eda/graph/results
```

`graph_metrics.py` содержит формулы доступности, анализ чувствительности и проверку треугольной согласованности. `analyze_graph.py` читает исходники, проверяет структуру, формирует таблицы и проверяет монотонность условного сценария. Конкретные параметры и трактовки записаны в `results/summary.json`.

Слово `observed` в машинных полях означает заполненное значение исходной модели, а не эмпирически измеренную поездку. Сценарий является изменением параметра OD-таблицы; не моделирует строительство и не доказывает реализуемость транспортного проекта.

- `results/accessibility.csv`: все 180 городов, два варианта выбора транспорта, пороги 6/12/24 часа и потенциалы с τ=6/12/24 часа.
- `results/rank_sensitivity.csv`: чувствительность рангов к τ и сравнению road с best_ground.
- `results/city_coverage_by_region.csv`: представленность городов по региональным меткам.
- `results/missingness_by_city_mode.csv`, `missingness_by_region_mode.csv`: заполненность исходной матрицы.
- `results/ranking_examples.csv`: примеры верхних и нижних значений, включая нулевые условные нижние оценки при полном отсутствии данных по выбранным режимам.
- `results/hypothetical_scenario.csv`: изменение результатов при условном уменьшении времени Кострома — Обнинск.
- `results/summary.json`: структурные проверки, диапазоны, соответствие времен формулам, треугольная согласованность и допущения.
- `findings.md`: содержательные выводы и ограничения.
