# Как выбор пунктов назначения меняет оценку

Рассчитана отдельная диагностическая проверка: road, τ=12 часов, тот же исходный ZIP и одинаковая обработка пропусков. Сравниваются четыре определения множества целей: все другие выбранные города; только города с исходным `is_capital=1`; все выбранные города вне того же административного региона; столицы по исходному флагу вне региона. Для каждого исходного города знаменатель — население допущенных городов назначения; собственный город исключён.

Это исследовательские определения целей, не утверждённые индексы команды. Пропуски дают нулевой вклад только в условную нижнюю оценку, а не доказывают недоступность. Население ВПН-2021; времена модельные.

## Флаг административного центра неполон как самостоятельный справочник

В 180 городах 84 имеют `is_capital=1`, 96 — нулевой флаг. Среди 85 региональных меток только Московская область не имеет ни одного отмеченного центра; все её 22 города имеют нулевой флаг. Регионов с несколькими единичными флагами нет. Поэтому `source_capitals` означает именно 84 города по полю источника, а не вручную проверенный полный справочник административных центров. Флаги не исправлялись.

## Результат не показывает радикальной неустойчивости рангов

| Сравнение со всеми другими городами | Spearman | Максимальный сдвиг места | Общих городов в top20 |
|---|---|---|---|
| Только центры по исходному флагу | 0,9983 | 15 | 19 |
| Только вне административного региона | 0,9984 | 12 | 17 |
| Центры вне административного региона | 0,9976 | 15 | 19 |

Общая пространственная картина для этих трёх изменений назначения очень похожа. Выдавать результат как доказательство сильной глобальной неустойчивости индекса было бы неверно. Однако цель меняет интерпретацию числа, отдельные позиции и состав верхней группы.

Примеры: Москва меняется с 46-го места на 61-е при выборе центров; потенциал с 0,294265 на 0,270704. Это результат смены целей и знаменателя, а не ухудшение транспортной системы. Великий Новгород в том же сравнении меняется с 64-го на 52-е место. При исключении своего административного региона Рязань меняется с 24-го на 12-е, Обнинск с 23-го на 14-е. При выборе центров вне региона Петрозаводск меняется с 94-го на 79-е.

## Административное исключение не означает исключение агломерации

Москва и Московская область — разные региональные метки источника. При исключении собственного региона Москва остаётся допустимой целью для всех городов Московской области, а города Подмосковья — целями для Москвы. Для Люберец число целей уменьшается со 179 до 158, но Москва остаётся в наборе. Таким способом нельзя отделить внутригородские, агломерационные и межрегиональные поездки по их функциональному смыслу. Радиусы или границы агломерации не придумывались.

## Что это позволяет решить

До утверждения индекса нужно выбрать, какие возможности должны быть доступны и кому: население всех выбранных городов, административные центры, конкретные рабочие места, медицина или доставка — разные множества целей. Представленные данные позволяют прозрачно сравнить несколько формальных определений и показать чувствительность. Они не говорят, какое определение верно для задачи команды. Отдельно нужно проверить справочник целей; source flag 84/85 уже показывает, что название поля не заменяет такую проверку.

Воспроизведение:

```bash
python destination_sensitivity.py --input-root /Users/andreykuronskin/keys_champ/datasets/intercity_connectivity --out results
```

В `results/` находятся все 720 оценок, сравнения рангов, сдвиги для каждого города, верхние примеры, региональная сводка флагов и JSON с точными допущениями. Предыдущие результаты основного EDA не изменялись.
