## Покрытие и ограничения

Сохранены исходный JSON, тело публичного POST-запроса, расшифровки фильтров и длинная CSV-таблица. Это один полный показатель, не вся ЕМИСС и не все доходы, занятость, цены и торговля из исходной строки. Служебные идентификаторы и первоначальная запись чисел с запятой сохранены. Территориальные уровни смешаны; названия перечислены в profile.json.

Полные машинные характеристики — в [metadata.json](metadata.json). SHA-256, исходные адреса и размеры записаны для каждого сохранённого файла.

Результаты полного прохода по CSV/ответу API — [profile.json](profile.json). Пустые строки и служебные коды не отождествляются автоматически с нулём.

## Как читать

Архивы сохранены в исходном виде. CSV Точно используют UTF-8 и разделитель `;`; таблицы можно читать потоково через `zipfile` и `csv`, без распаковки больших файлов на диск. Таблицы в `derived/` получены явно описанным преобразованием исходников, не являются синтетическими данными. Для ЕМИСС используется запятая как разделитель столбцов длинной CSV.

Исходные и промежуточные файлы `raw/` и `derived/` не включены в Git. Имена в таблице обозначают локальные файлы исторического исследования; адреса загрузки и контрольные суммы приведены в `metadata.json`.
