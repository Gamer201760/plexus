# Медицинские организации ОМС — национальные реестры

Проверено и скачано 9 ноября 2026 года. Это отдельное приобретение данных: расчёты и продукт не изменены.

Получен **реальный национальный F032**, а не только каталог ссылок: 9980 строк,
91 значение `SUBJ`, **82 из 82 регионов атласа**. Источник — официальный
[ТФОМС Камчатского края, пакет НСИ](https://www.kamtfoms.ru/informacionnye_resursy/paket_nsi/),
который публикует федеральные классификаторы. Исходные ZIP/XML сохранены без изменений.

| Набор | Скачано | Содержание и дата |
| --- | ---: | --- |
| [F032](https://www.kamtfoms.ru/files/packet_NCI/f032_5_267_xml.zip) | 9980 строк | ОМС, версия 5.267; внутри XML `03.03.2026`, записи программы 2026 |
| [F001](https://www.kamtfoms.ru/files/packet_NCI/f001_7_68_xml.zip) | 90 фондов | Каталог ТФОМС с кодом, ОКАТО и официальным сайтом; XML `15.10.2025` |
| [F031](https://www.kamtfoms.ru/files/packet_NCI/f031_4_167_xml.zip) | 8734 строки | Единый реестр МО; версия 4.167; заголовочная дата XML пуста, страница указывает 18.06.2025; не выдавать за свежий 2026 |
| [F033](https://www.kamtfoms.ru/files/packet_NCI/f033_3_409_xml.zip) | 137907 строк | Структурные подразделения, версия 3.409, XML `03.03.2026` |

У F032 на странице ошибочно/неактуально указано `04.03.2025`, хотя скачанный
архив содержит XML от 03.03.2026 и `D_BEGIN_OMS` 2026 года. Для датирования этой
выгрузки используем содержимое XML и сохраняем расхождение. Это мартовский снимок,
а не гарантия актуальности на ноябрь.

F032 содержит имена, ИНН/ОГРН, тип МО `VID_MO`, коды, контакты и **юридический**
адрес `JURADDRESS_ADDRESS`. `SUBJ` обозначает территорию реестра/программы, поэтому
юридический адрес организации из записи Адыгеи может находиться в Москве.
Это не полный реестр фактических мест оказания помощи и не геокодированные точки.
Нет координат, расписаний, вместимости или подтверждения доступности услуг.
F033 содержит названия и типы подразделений, включая ФАП; адресов и координат
в этой схеме нет. F031 содержит `ADDR_J`, также юридический адрес. Для замены
ставропольских фактических адресов и профилей эти файлы требуют дальнейшего
сопоставления с реестрами мест оказания помощи; наличие записи не доказывает
географическую доступность.

`region-crosswalk.json` сохраняет соответствие всем регионам атласа и число
строк. Метод: точное `SUBJ` плюс пять явно записанных вариантов названий:
Кемеровская область, Северная Осетия, ХМАО, ЯНАО и Еврейская АО.
`coverage.json` содержит исключения и список дополнительных категорий.
За пределами атласа: Москва, Санкт-Петербург, Севастополь, Байконур,
Донецкая/Луганская Народные Республики, Запорожская/Херсонская области,
`Российская Федерация`. Названия и административная классификация сохранены
как в источнике; последняя категория содержит федеральные организации.

Коды не взаимозаменяемы: `region_id_if_known` — идентификатор проекта,
`tf_okato` — ОКАТО из F001, `tf_kod` — код фонда ОМС. Префиксы `UIDMO` F032
сопоставлены с `tf_kod` по наблюдаемому содержимому этого снимка. Это не код
Минтранса и не универсальное правило для будущих версий. Необычные исходные
значения `tf_okato` сохранены; сопоставление с атласом сделано по названию,
а не арифметикой кодов.

Дополнительно проверены [реестры Московской области](https://www.mofoms.ru/dokumenty/spravochniki/reestry/)
и [ДНР](https://fomsdnr.ru/reestrmo): оба файла 2026 года скачаны и проверены
как исправные ZIP/XLSX-контейнеры. Московская область публикует версию от
14.10.2026; построчная сверка этих двух книг с мартовским F032 не выполнялась.
Страницы Владимирской области и Дагестана найдены поиском, но прямое чтение
дало 403/таймаут; локальные региональные файлы по ним не получены.

[Национальный каталог FFOMS](https://www.ffoms.gov.ru/system-oms/territorial-funds/)
найден по ссылке официального Московского ТФОМС, однако чтение не удалось.
Сохранён [официальный каталог Чеченского ТФОМС](https://tfoms-chr.ru/Prochaja-informacija/Perechenq-ssylok-na-sajty-gosudarstvennyx_organov/moskovskaya-area)
как дополнительное свидетельство региональных сайтов. В нём есть подозрительная
ссылка ЛНР на домен ДНР, поэтому основой машинного списка служит F001.
**90 записей каталога F001 не означают 90 проверенных региональных реестров**:
сайты из каталога отдельно не обходились. Национальное покрытие подтверждено
именно строками скачанного F032.

Файлы:

- `sources.json`: 186 записей источников, включая 91 региональную категорию национального реестра, 90 записей каталога и 5 отдельных проверок.
- `manifest.json`: размер, SHA256 и дата приобретения каждого файла.
- `schemas.json`: заголовки XML и фактически обнаруженные поля с числом присутствий.
- `f001-funds.json`, `region-crosswalk.json`, `coverage.json`: каталог и проверяемое покрытие.
- `data/additional/all-regions-medical/raw/`: архивы, исходные страницы, две региональные книги.
- `data/additional/all-regions-medical/f032-organizations.jsonl.gz`: все 9980 строк F032, без потери исходных полей; пустой XML-элемент представлен пустой строкой.

Воспроизведение проверки: `python3 datasets/additional/all-regions-medical/inspect_registries.py`.
Скрипт работает локально, не обращается к сети. Для повторного запуска требуется
`datasets/additional/all-regions/atlas-regions.json`; в исследовательском worktree
допускается чтение этого файла из исходного проекта. Проверены целостность всех
шести ZIP/XLSX-контейнеров, XML-разбор четырёх федеральных справочников, полное
покрытие 82 регионов и отсутствие пропущенных регионов в сопоставлении.
