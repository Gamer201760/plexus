# Сезонные открытия, закрытия и ограничения

`data/additional/seasonal-closures/events.csv` содержит 30 проверенных наблюдений из сообщений МЧС по 10 регионам за 2025–2026 годы. Это начальный событийный набор, не полный реестр России. Полный текст 21 подходящей публикации сохранен в `articles.json`; неизмененные HTML и их контрольные суммы находятся в архиве `transport-operations`.

Четыре строки содержат установленную дату события. Для остальных указан статус на момент сообщения; дата публикации **не выдается за точный день открытия или закрытия**. Есть отдельные поля для вида состояния, уровня обобщения (переправа/регион), числа объектов и ограничения массы. Региональные количества не являются отдельными ребрами графа. Принятие понтонного моста Нижнеленинское — Тунцзян к зимней эксплуатации не отнесено к ледовым дорогам.

Одна запись сводки Югры за 2026 год содержит в самом тексте дату 31.03.2025. Она сохранена с `quarantined_date_conflict`: не включать ее в временной ряд без дополнительного подтверждения. Плановые числа из сводок не используются вместо действующих объектов.

Ручная разметка с проверяемыми фрагментами — `annotations.json`. Команда `python3 datasets/additional/seasonal-closures/derive.py` проверяет наличие каждого фрагмента в скачанном источнике и воспроизводит CSV. Для подробной многолетней истории Югры используйте отдельный набор `seasonal-ugra`.

Из этих наблюдений нельзя автоматически вычислить число дней изоляции: нужны пары открытия/закрытия одного объекта, сведения о замещающих перевозках и проверка пропусков сообщений. Даты и правила движения относятся к конкретному сезону, а не к постоянному состоянию дороги.
