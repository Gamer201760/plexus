# Дорожная и железнодорожная сеть OSM — Уральский округ

Сбор 08.11.2026. География — весь Уральский федеральный округ, включая Югру и соседние регионы. Это исходный слой для построения графа и поиска альтернативных путей. Выгрузка не ограничена административной границей Югры.

Источник: https://download.geofabrik.de/russia/ural-fed-district.html
Закреплённый снимок: `ural-fed-district-261106.osm.pbf` (дата содержимого уточняется по заголовку PBF в `profile.json`). Используется конкретная версия, а не изменяемый `latest`.
Лицензия: OpenStreetMap contributors, ODbL 1.0, https://www.openstreetmap.org/copyright.

## Файлы и воспроизведение

```sh
python3 datasets/additional/osm-ural/acquire.py
.venv/bin/python datasets/additional/osm-ural/extract.py
```

Требуются `osmium` и `pyarrow` из зависимостей проекта. `acquire.py` сохраняет PBF, контрольную сумму поставщика и страницу источника в `data/additional/osm-ural/raw/`; проверяет MD5 и записывает SHA-256 каждого файла в `manifest.json`. Незавершённая загрузка имеет суффикс `.partial`.

`extract.py` формирует `data/additional/osm-ural/derived/network_ways.parquet`. Сохраняются ID и версии OSM ways, время изменения, ID вершин, широта/долгота каждой вершины, все исходные теги JSON и отдельные поля `highway`, `railway`, `route`, `bridge`, `surface`, `oneway`, `access`, `maxweight`, `seasonal`. Координаты WGS84 в градусах; значения ограничений остаются исходными строками с единицами поставщика. Счётчики и хеш результата — `profile.json`.

## Ограничения

Количество ways — количество сегментов OSM, а не уникальных дорог или мостов. Один мост может состоять из нескольких сегментов. Отсутствующий тег не подтверждает отсутствие ограничений или круглогодичную работу. В исходный слой входят также пешеходные, частные, железнодорожные и паромные объекты; транспортная фильтрация пока не применена. Разрешённые направления, правила проезда, сезонность, связность и привязку конкретного официального объекта требуется проверить при построении модели. Набор сам по себе не является рассчитанным графом или подтверждением состояния дороги на дату поездки.
