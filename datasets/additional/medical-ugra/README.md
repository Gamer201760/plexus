# Медицинские организации и адреса помощи Югры

Скачан официальный реестр ТФОМС ХМАО — Югры организаций, участвующих в территориальной программе ОМС **на 2026 год**. Включает государственные и частные организации; это не полный реестр всей медицины региона. Источник: [реестры и справочники ТФОМС](https://www.ofoms.ru/страницы/реестры-и-справочники), [первичный XLSX](https://www.ofoms.ru/uploads/files/7eb202f860af4b038bcfba67ec9e03ea/trmo052026.xlsx).

## Полученные данные

- `data/additional/medical-ugra/raw/trmo052026.xlsx`: первичный файл, внутреннее время изменения книги `2026-05-12T06:24:19Z`. Год реестра и дата скачивания не означают проверку фактической работы учреждений на сегодня.
- `raw/ofoms-register-index.html`: страница публикации.
- `raw/city-ugut.html`: дополнительная официальная карточка больницы Угута; не используется для автоматической подмены адресов реестра.
- `derived/care_records_2026.{csv,json}`: **2 121** строка реестра, **115** организаций; адрес оказания помощи, подразделение/OID, виды, условия и профили помощи, юридический адрес в отдельном поле. Каждая строка имеет исходный URL, имя листа и номер строки Excel.
- `derived/organizations_2026.{csv,json}`: **115** организаций, сведения из первой строки каждой организации.
- `derived/care_locations_exact_address_2026.{csv,json}`: **1 077** пар «организация + точный адрес оказания помощи», с номерами исходных строк, OID подразделений и идентификаторами ГАР. Это адресные группы, не подтвержденные уникальные здания. Разные написания не объединялись; несколько организаций могут работать по одному адресу.

Во всех 2 121 строках заполнены адрес помощи, профили помощи и OID подразделения. Координаты и часы работы в источнике отсутствуют: JSON содержит `null`, CSV — пустые поля. Отсутствие даты исключения не доказывает, что подразделение сейчас работает. Профиль «хирургия» не подтверждает круглосуточную экстренную хирургическую помощь, наличие операционной, персонала или мощностей. Нельзя использовать эти данные для подтверждения медицинской доступности без геопривязки и проверки режима/целевого вида помощи.

`registered_address` — адрес регистрации организации; `care_address` — опубликованный адрес оказания помощи. Для маршрутизации предназначен второй, после отдельной проверки и геопривязки. Строковые даты сохранены в опубликованном формате. Профили/условия/виды помощи сохранены как текст источника, без придуманной классификации. `source_rows`, `department_oids`, `address_gar_ids` в адресной таблице разделены `;`. Персональные данные пациентов и поля сотрудников в производные таблицы не извлекаются.

## Воспроизведение и контроль

Из корня репозитория, Python 3 без внешних библиотек (для загрузки требуется curl):

```sh
python3 datasets/additional/medical-ugra/acquire.py
python3 datasets/additional/medical-ugra/extract.py
```

`download-log.json` содержит URL, время и результат загрузки; `manifest.json` — размеры, SHA256 и время файлов; `profile.json` — фактические счетчики. Повторное скачивание может получить обновленную версию файла, поэтому результаты следует сверять с манифестом.

Дополнительная попытка открыть официальный сайт Угутской больницы `https://med-b-ugutskaya-r86.gosweb.gosuslugi.ru` завершилась ошибкой curl 60 (невозможно проверить локальную цепочку сертификата). Проверка TLS не отключалась; услуги и часы с этого сайта не получены. Сведения из основной выгрузки ТФОМС доступны независимо от этой ошибки. Подробности — `additional-attempts.json`.
