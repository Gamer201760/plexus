# Ненецкий автономный округ: второй проход

Дата: 2026-11-09. Получены 3 автобуса и 29 новых пар соседних авиационных посадок. Данные не подключены к расчётному графу.

## Автобусы

[Официальная страница департамента](https://gkh.adm-nao.ru/transport/) называет действующим реестр с 01.01.2025. Оригинал raw/reestr_mm_s_01.01.25.xlsx, HTML raw/transport.html. Из первого листа взяты все 3 маршрута: 411 и 413 Нарьян-Мар — Искателей, 415 Искателей — аэропорт Нарьян-Мара. Все концы сопоставлены; аэропорт отнесён к городу.

Частоты рассчитаны из второго листа для периода 01.09–31.05: рабочие отправления × 5 плюс выходные × 2. Это одна сторона типовой недели без праздников; летний график иной. Дневные числа и формула сохранены в schedule_note.

## Авиация

Первичный источник — [живой API расписаний](https://avianao.ru/content-api.php?action=schedules), связанный с [сайтом перевозчика](https://avianao.ru/) скриптом avianao-site.js. Ответ повторно скачан в raw/schedules-current.json; HTML и JS сохранены. updated_at: 2026-08-24. Старые адреса /zim-rasp/ дают 404, использован действующий API.

В links_add.csv только 29 пар соседних посадок зимних рейсов. Обратные направления объединены; источник не доказывает симметричную частоту, поэтому числовые частоты оставлены пустыми. В заметках номера рейсов, дни/даты и сезонные ограничения. Существующие пары каталога исключены.

30 числовых кандидатов частот поездки из Нарьян-Мара помещены в raw/frequency_candidates.csv, ещё 3 новых поездки — raw/journey_candidates.csv. Это пути через промежуточные посадки; исходные рёбра старого каталога не определяют такую семантику. Автоматически интегрировать их нельзя. Канонический freq_fill.csv пуст. Числа кандидатов ограничены октябрём–декабрём 2026, не всем годом.

Водные линии, зимники и переправы не получили подтверждённых дополнений. Публикация расписания не подтверждает фактическое выполнение. CSV разобраны, ID проверены; тесты продукта не запускались.
