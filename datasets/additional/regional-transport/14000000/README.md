# Белгородская область (14000000): второй проход, регулярные автобусы

- Официальный реестр межмуниципальных маршрутов (220-ФЗ) не найден. В меню сайта минтранса области https://mintrans.belregion.ru/transport (проверено 2026-11-09, копия в `raw/`) нет раздела реестра: там только конкурсы, такси и расписание агломерации. Поиск по сайту, belregion.ru и веб-поиск реестр не выдали. data.belregion.ru отвечает 502, opendata.belregion.ru не резолвится.
- Вместо реестра взяты два источника, у всех строк confidence=medium.
- 1) Расписание ОГКУ «ОПП Белгородской области» (организатор перевозок при правительстве области) на период с 01.02.2026 по 31.01.2027: https://transport-31.ru/raspisanye/ . Данные получены из JSON, который грузит встроенный виджет: https://admin2026.busmap31.ru/api/transport31 (сохранён в `raw/`). Из 130 маршрутов агломерации взяты 85 с номерами 100+ (route_kind=suburban). По новости ОПП от 30.01.2025 в сети 46 городских и 84 межмуниципальных пригородных маршрута, поэтому граница по нумерации может ошибаться на один-два маршрута.
- 2) Табло отправлений АВ Белгород, обновлено 21.10.2026: https://avtovokzal31.ru/belgorod/raspisanie-avtobusov/ . Взяты 56 рейсов до пунктов внутри области (route_kind=intermunicipal), рейсы за пределы области исключены. Номер рейса записан в registry_no, промежуточные пункты из «ч/з …» — в via.
- Итого 141 маршрут. Оба конца сопоставлены с н.п. входного списка у 100 маршрутов: 49 из 85 пригородных и 51 из 56 междугородных.
- Без ID остались микрорайоны («Таврово-3», «Разумное-54», «Стрелецкое-73/1» и т.п.), сады, остановки с неясной принадлежностью (СитиМолл, Амбар, Ячнево, Аквапарк), «Сах. завод», а также названия, которых нет во входе или которые там написаны иначе (х. Сумской, Малые Кульбаки, Болховец, «Батрацкие дачи»).
- trips_per_week есть у 139 строк. Для агломерации это отправления в неделю от начального пункта, по дням недели; рейсы только в праздники и отметки «выходной» не учтены, обратное направление указано в schedule_note. Для АВ Белгород считаются только отправления из Белгорода; у рейсов «каждый 2-й день» частота не выводилась.
- km и carrier источники по маршрутам не дают, поэтому поля пустые. season=all ставится только для несезонных маршрутов из годового расписания ОПП. Сезонные маршруты (сады, Верхний Ольшанец, Малые Кульбаки) оставлены с пустым season, потому что период не указан. Для табло АВ season тоже пустой.
- Не получено: расписания автовокзалов Старого Оскола, Губкина и других городов, поэтому маршруты между районами без захода в Белгород не охвачены. Страница АВ Белгород-ЖД на avtovokzal31.ru устарела (обновлялась 07.07.2024) и не использовалась. www.belg-gov.ru показывает проверку браузера.
- freq_fill.csv пустой: в первом проходе 0 строк, частоты заполнять нечему.
- links_add.csv пустой. Новых авиа-, речных и паромных связей, зимников, понтонных и ледовых переправ не найдено; это типично для региона. В сообщениях 2025–2026 годов речь идёт только о повреждении постоянных мостов в приграничье, сезонных переправ там нет. Аэропорт Белгорода закрыт с 24.02.2022 (см. первый проход).
- Отличие от первого прохода: там транспортный CSV был пустым (только remote-перечень), здесь впервые собраны регулярные автобусные связи из Белгорода и Белгородской агломерации.
