# Республика Адыгея (79000000) — межмуниципальные автобусы, второй проход

- Источник: официальный реестр Минстроя РА «РЕЕСТР межмуниципальных маршрутов РА 2016 на 21.06.2017.xls». Ссылка на него стояла на странице [minstroyra.ru/transport-149](https://web.archive.org/web/20210115134408/http://www.minstroyra.ru/transport-149/) в снимке Wayback от 2021-01-15. Сам файл скачан из [Wayback, снимок 2018-02-05](https://web.archive.org/web/20180205141704/http://minstroyra.ru/media/userfiles/%D0%A0%D0%95%D0%95%D0%A1%D0%A2%D0%A0_%D0%BC%D0%B5%D0%B6%D0%BC%D1%83%D0%BD%D0%B8%D1%86%D0%B8%D0%BF%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D1%85_%D0%BC%D0%B0%D1%80%D1%88%D1%80%D1%83%D1%82%D0%BE%D0%B2_%D0%A0%D0%90_2016_%D0%BD%D0%B0_21.06.2017.xls). Оригинал и снимок страницы лежат в `raw/`. Новее версии найти не удалось.
- Живой сайт minstroyra.ru за Cloudflare отдаёт 403 (curl, WebFetch, r.jina.ai; проверено 2026-11-09). Поиск и портал adygheya.ru актуального реестра не дали; HTTPS на adygheya.ru сбрасывает соединение.
- `bus_routes.csv`: 65 строк. 63 из них из реестра 2017 г. (`confidence=high`, `source_date=2017-06-21`), все `route_kind=intermunicipal`: реестр не делит маршруты на пригородные и междугородные. Межрегиональных маршрутов в реестре нет. Ещё 2 строки взяты из «Адыгеи Сегодня» со ссылкой на Минстрой РА (`low`): Майкоп – Кошехабль, открыт [12.05.2025](https://adigeatoday.ru/news/60229.html); №145 Шаумян – Майкоп, возобновлён [27.02.2025](https://adigeatoday.ru/news/58878.html).
- Сопоставление: оба конца у 61 из 65 маршрутов (59 из 63 строк реестра), хотя бы один у всех 65. Без id остались х. Шевченко (во входе нет; одноимённый хутор Теучежского района дальше протяжённости маршрута), х. Грозный (два хутора в Майкопском районе), Учебное лесничество и х. Веселый (несколько одноимённых). Пункт «ВИР» сопоставлен с пос. Садовый Тимирязевского с/п по промежуточным пунктам. Автокассы, Центральный рынок и Западный жилой район отнесены к Майкопу.
- `via`: из перечня остановок реестра взяты только населённые пункты с префиксом (х., ст., п., а., с.). Повороты («пов. на …») не включены.
- `trips_per_week` заполнен у 17 строк реестра и у обеих строк из СМИ. Считались отправления из начального пункта, где реестр указывает дни (ежедневно, «кроме сб., вс.», «пн., ср., пт.» и т. п.). Праздники не учтены. Где дни не указаны, число отправлений записано в `schedule_note`.
- Актуальность: реестру 9 лет. [Сообщение от 05.01.2026](https://adigeatoday.ru/news/64366.html) подтверждает работу маршрутов из Майкопа на Тульский, Табачный, Кужорскую, Гиагинскую, Абадзехскую, Хаджох, Первомайский, Шевченко, Гузерипль, Шаумян и Кошехабль. Остальные маршруты 2017 г. могут быть изменены или закрыты.
- `freq_fill.csv` содержит только заголовок. Расписание катера Новый – Краснодар на выходные не найдено, поэтому недельная частота не выведена.
- `links_add.csv` содержит только заголовок. Первый проход уже проверил авиацию, зимники, речные линии и понтоны. Это юг страны, новых сезонных связей не найдено.
- Отличие от первого прохода: тот нашёл одну переправу. Второй проход добавил межмуниципальную автобусную сеть по официальному реестру. Муниципальные реестры (Майкоп, сельские поселения) не собирались.
