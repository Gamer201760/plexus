# Тверская область (28000000): второй проход

- **Реестр найден.** Минтранс Тверской области публикует реестр межмуниципальных маршрутов на [странице реестров](https://mintrans.tverreg.ru/transportnaya-otrasl/avtomobilnyy-transport/reestr-munitsipalnykh-i-mezhmunitsipalnykh-marshrutov-tverskoy-oblasti). Актуальный файл — `Реестр межмуниципальный_20260909…xlsx`, редакция от 09.09.2026, скачан 09.11.2026. Копии лежат в `raw/`. Из него в `bus_routes.csv` перенесены все 195 маршрутов с confidence=high. Муниципальный реестр не использовался.
- **Сопоставление с н.п.** Оба конца сопоставлены у 175 из 195 маршрутов, один конец — у 16, ни одного — у 4. Остановки внутри Твери, Ржева, Торжка, Кимр и Бологого (вокзалы, площади, улицы, Мамулино, Пролетарка) отнесены к своему городу. Конечные пункты, которые не являются населёнными пунктами, оставлены без id: СНТ, ПК «Аквариус», санаторий «Прометей», Щупинское кладбище, «Ржевский мемориал», Калининская МИС, «Березка». Без id остались и неоднозначные концы: Дмитровское у 308, Высокое у 323, Антоново у 350, оба конца у 457.
- **route_kind.** Значение suburban получили пригородные маршруты Твери (1xx–2xx), Кимр, Торжка, Ржева и Бологого — 120 маршрутов. Остальные 75 отмечены как intermunicipal. Межрегиональных маршрутов в реестре нет. В `via` записаны промежуточные остановки прямого направления из реестра.
- **trips_per_week заполнен у 161 маршрута.** Число посчитано по расписаниям, на которые ссылается реестр: 81 PDF на сайте минтранса и 77 xlsx на Яндекс.Диске. Копии лежат в `raw/schedules/`. Отправления с конечного пункта умножены на число дней: рабочие дни ×5, выходные ×2, конкретные дни — по сноскам. В поле записано большее из направлений (у сеток по часам — большее по конечным пунктам), все числа приведены в `schedule_note`. По маршрутам 332–341 использовано сводное расписание «Ржев – пригород» от 01.09.2024. Часть расписаний действует с 2022–2024 годов. Подсчёт по сложным таблицам может ошибаться на 1–2 рейса.
- **Частоты нет у 34 маршрутов.** У 27 расписание в реестре не указано (308, 324–330, 355, 503в, 506, 506м, 510, 521, 521т, 536, 543, 550, 551, 555, 559, 560, 372–375, 3А, 7Б). Файлы 362 и 369 открываются без таблиц. Маршрут 526 ходит в 1-ю и 3-ю субботу месяца. К маршруту 116 приложено чужое расписание (Старица). Маршруты 154к, 177к и 222к работают только в отдельные даты. У 14 маршрутов в реестре не указан перевозчик.
- **freq_fill.csv — только заголовок.** Не найдено датированных источников 2025–2026 годов с частотами теплоходов Конаково — Завод 1 Мая и Селигерских линий «Звезды». То же относится к зимнику Конаково — 1-е Мая. Страница [«Водный транспорт» минтранса](https://mintrans.tverreg.ru/transportnaya-otrasl/vodnyy-transport-/) (без даты, сохранена 09.11.2026) подтверждает только три регулярные линии: Завод 1 Мая — Конаково, Южная — Осташков, Южная — Пачково. Линии Южная — Пески на этой странице нет, частоты не указаны.
- **links_add.csv — только заголовок.** Паром «Зеленый Бор — Топорок» подтверждён минтрансом, но Зеленого Бора Конаковского района нет во входной таблице, поэтому строку составить нельзя. Паромная переправа №1 в Дубне ([360.ru, 23.04.2026](https://360.ru/news/mosobl/paromnaja-pereprava-mezhdu-podmoskovem-i-tverskoj-oblastju-vozobnovila-rabotu/), зимой понтон) лежит на подъезде к Конаковскому району, точный тверской берег не указан, поэтому она не добавлена. Регулярной авиации нет: страница [«Авиация»](https://mintrans.tverreg.ru/transportnaya-otrasl/aviatsiya-/) называет только площадки АОН и вертодром, в паспорте региона Росжелдора от 24.08.2026 указано «0 аэропортов». Зимники и ледовые переправы сверх первого прохода не найдены.
- **Ограничения.** Сертификат rlw.gov.ru не прошёл проверку, поэтому PDF скачан с `-k`. Лимит веб-поиска сессии исчерпан до поиска частот Селигера и Дубненской переправы.
- **Отличие от первого прохода.** Первый проход собрал только 5 сезонных речных и зимних связей. Этот проход добавил весь официальный автобусный реестр с частотами и официальную страницу о водном транспорте. Строки первого прохода не дублировались.
