- Дополнительно скачан «Реестр действующих свидетельств и карт маршрута» на ту же дату (https://mintransdag.ru/activity-attachments/332/download) — `raw/reestr_svidetelstv_i_kart_marshruta_rd.xlsx`, в CSV не разбирался (только номера свидетельств/карт и число ТС).

- Сопоставлено с н.п. входного списка на обоих концах: 350 из 373; на одном конце — 23. Не сопоставлены пункты, которых нет во входе (кутаны, совхозы, Ботаюрт, Боташюрт, Сивух, Хамзаюрт, Верхний Чирюрт, Новые Бухты и др.), неоднозначные (Белиджи п./с. в № 377, Ишкарты, «Рубас-Коммуна») и аэропорт Махачкала. Автовокзалы сопоставлены с городом. Однофамильные сёла (Первомайское, Октябрьское, Куруш, Акнада, Тукита) выбраны по согласованию прямого расстояния с протяжённостью из реестра; это отмечено в schedule_note.
- via — н.п. с префиксом «г./с./п.» из графы «Наименование улиц и автомобильных дорог» (без «поворот на …»), 247 маршрутов.
- trips_per_week (370 из 373) — число отправлений в прямом направлении из листа «Расписание» × дни: «ежедневно» ×7, «ежедневно кроме пн» ×6. Для интервального движения («с 06:00 до 13:00 с интервалом 15 мин») расчёт: (конец − начало)/интервал + 1. Пусто: № 226/227 («через день»), № 482 (нет времён). Число обратных рейсов указано в schedule_note.
- `freq_fill.csv` — только заголовок: в первом проходе 0 строк, дополнять нечего.
- `links_add.csv` — только заголовок. Повторный поиск (местная/субсидируемая авиация, катера на о. Чечень, переправы) регулярных пассажирских связей не нашёл: вертолёты МЧС летают только при ЧС, на о. Чечень по Википедии постоянного населения нет, сведений о рейсах катеров нет. Зимников, паромов, понтонов и ледовых переправ в регионе нет.
- Отличие от первого прохода: первый собирал только сезонные/нерегулярные связи (0 строк, описание горных блокировок); здесь добавлен официальный реестр автобусных маршрутов с расписанием.
