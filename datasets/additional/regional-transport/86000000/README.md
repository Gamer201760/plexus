# Республика Карелия (86000000) — второй проход: регулярные автобусы и сезонные связи

- Реестр межмуниципальных маршрутов найден на сайте Минтранса Карелии (Министерство по дорожному хозяйству, транспорту и связи): https://road.gov10.ru/about/3925/ . Файл «Реестр маршрутов на 17.10.26 в ред. приказа № 210 от 13.10.26» (xlsx, 2026-10-17) лежит в `raw/reestr_mezhmun_karelia_2026-10-17.xlsx`.
- `bus_routes.csv`: 81 действующий маршрут, confidence=high. 5 маршрутов с отметкой «Отменен» исключены: 604, 606, 610, 616, 101А.
- Межрегиональных маршрутов в реестре нет. route_kind выведен из нумерации: серия 1xx — suburban, если ни один конец не райцентр, кроме Петрозаводска; маршруты на Кондопогу и Пряжу — intermunicipal; остальные — intermunicipal.
- Оба конца сопоставлены с н.п. входа у 63 из 81 маршрута. Без id остались конечные, которых нет во входе или которые неоднозначны: Лехнаволок, гарнизон Бесовец, дачи Падозеро 28/33 км, Шапшезеро, Пиньгуба, Дачи 31 км, дачи Орзега, Лучевое-1/2, Дачи Бесовец 13 км, Порожки. Эссойла тоже без id: во входе есть пос. и с. Эссойла.
- via заполнен промежуточными пунктами из названия маршрута; полные списки остановок есть в реестре. Спорные сопоставления описаны в schedule_note: Чална — пос. Чална Пряжинского р-на, «Уя 29 км» — д. Уя.
- trips_per_week пуст во всех строках. В столбце «Расписание» реестра вместо расписания стоит ссылка https://vk.com/avokzal.karelia, поэтому частоту из реестра не вывести. Расписания по Яндекс.Расписаниям не собирались. season пуст: реестр сезонность не указывает.
- `freq_fill.csv` пуст. Для вертолёта Петрозаводск — Сенная Губа недельная частота в источниках не нашлась. Ми-8 «по понедельникам» в межсезонье описан для рейса на Кижи (https://samokatus.ru/karelia , 2023), но не для Сенной Губы, поэтому его не переносили.
- `links_add.csv`: 3 новые связи с confidence=low:
  - Сортавала — Валаам, «Метеор» ежедневно 08.05–20.09.2026: https://travelto.ru/blog/chto-vzjat-na-valaam/ (2026-08);
  - Рабочеостровск — Соловки (ext:Соловецкий), теплоход/катер июнь–сентябрь: https://travelto.ru/blog/chto-vzjat-na-solovki/ (2026-08);
  - Кемь — Соловки, понтонная перевозка автомобилей май–ноябрь без расписания: runews24.ru, 2026-05-25.
- Чем отличается от первого прохода: первый собрал только водную линию и авиарейс Петрозаводск — Лонгасы/Сенная Губа (3 строки). Здесь добавлены автобусный реестр, Валаам и Соловки. Социальный «Метеор» на Кижи с заходом в Лонгасы в 2026 году снова работал по ср/пт/вс с 22 мая (по выдаче поиска; дубль не создан).
- Не нашлось или было недоступно:
  - gov10.ru и road.gov10.ru отвечают нестабильно (TLS reset, таймауты), xlsx скачался с 4-й попытки;
  - karelia-gov.ru — сторонний архив документов с JS-проверкой;
  - нет пар берегов и координат для ледовых переправ (Водла, Колода, Кемь у Панозера) и сведений о запуске парома Панозера в 2026 году;
  - нет зимнего сообщения с Валаамом с указанием пункта отправления, нет местной авиации внутри региона с расписанием.
