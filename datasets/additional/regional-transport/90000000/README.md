# Республика Северная Осетия — Алания (90000000): второй проход

- Найден официальный реестр межмуниципальных маршрутов Комитета РСО-Алания по транспорту: «Реестр межмуниципальных маршрутов на 17.07.2026», страница https://komtrans.alania.gov.ru/pages/79 (раздел «Перечни … реестров», проверено 2026-11-09). Оригинал: `raw/reestr_mezhmun_2026-07-17.xlsx` (лист «Реестр» + 74 листа расписаний по маршрутам).
- `bus_routes.csv`: 75 маршрутов реестра (все автобусные, `route_kind=intermunicipal`, `confidence=high`, `source_date=2026-07-17`). Межрегиональных маршрутов в региональном реестре нет. Муниципальный реестр (pages/81) и трамвайный (pages/80) не собирались.
- Сопоставление: 70 из 75 маршрутов сопоставлены с н.п. входа с обоих концов. Не сопоставлен один конец у 5: № 108А «Среднее Дачное» и № 111А «Восход» (нет во входе), № 129 «ВТРК Мамисон» и № 208 «Цей» (курорты, Цей неоднозначен), № 254 «Урсдон» (по остановкам это Кора-Урсдон Дигорского р-на, во входе отсутствует; одноимённый Урсдон Алагирского р-на не подставлен).
- Ручные решения: Дзуарикау (№ 116, 121) — с. Дзуарикау 90605410101 на Транскаме; «Цмти» (№ 139) — Цмити Ардонского р-на (идёт через Коста, Фарн); Ногкау (№ 153) — Ногкау Алагирского р-на; «Старый Батако» — с. Батако; «Аэропорт (Беслан)» и «Беслан (ЖДВ)» — г. Беслан; «Сунжа (сок.цех/хутор/…)» — с. Сунжа; «Камбилеевская» — с. Камбилеевское.
- `via` — только н.п. из графы «промежуточные остановочные пункты» (без улиц, поворотов, садов), в порядке реестра.
- `trips_per_week` заполнен у 48 маршрутов: число отправлений в прямом направлении листа расписания × 7 (все такие листы «ежедневно», «круглогодично»). Пусто у 27: интервальные расписания (интервалы, без числа рейсов), неоднородные листы с промежуточными пунктами (№ 126, 169, 170, 201, 208, 218, 301, 303, 305), пустой лист № 109Г, нет листа у № 131. Пояснение — в `schedule_note`.
- У 7 маршрутов в реестре не указан перевозчик (№ 109А, 109Г, 131, 133, 185, 203, 184) — `carrier` пуст.
- `freq_fill.csv`: пусто — в первом проходе 0 строк, дополнять нечего.
- `links_add.csv`: пусто. Местной/субсидируемой внутрирегиональной авиации, зимников, речных линий, паромов, понтонных и ледовых переправ в регионе не найдено (горный юг, аэропорт Владикавказ обслуживает только межрегиональные рейсы); отдельный поиск не проводился, вывод согласуется с первым проходом.
- Блокеры: сайты *.alania.gov.ru отдают сертификат российского УЦ, не доверенный в системном хранилище; загрузка выполнена без проверки цепочки (curl -k), файл — официальная публикация. 403/капчи не было.
- Отличие от первого прохода: первый проход искал только сезонные/специальные связи и дал 0 строк; второй добавил полный официальный реестр автобусных межмуниципальных маршрутов с расписаниями.
