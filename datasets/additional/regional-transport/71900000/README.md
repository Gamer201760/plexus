# Ямало-Ненецкий автономный округ: частичный второй проход

Дата: 2026-11-09. Результат: 1 автобусный маршрут и 12 новых пар вертолётных посадок. Полный автобусный реестр округа не получен.

[МАТП Салехарда](https://www.matp-salekhard.ru/marshrutyi/marshrut-11-do-30.06.2025-g/) публикует маршрут 11 Салехард — Горнокнязевск и схему остановок; raw/route11.html. Страница находится в [текущем каталоге](https://www.matp-salekhard.ru/marshrutyi/), raw/matp.html. Дата в slug не трактуется как дата актуальности: source_date пуст. Частота не извлечена. Это линия одного перевозчика, не полный региональный охват.

[Официальное расписание АК Ямал](https://akyamal.ru/passazhiram/raspisanie-dvizheniya/), raw/helicopters.html, содержит рейсы 2026. Старый каталог уже включал пары Салехард — конечный пункт, они не продублированы. Добавлены только отсутствовавшие пары соседних промежуточных посадок, например Салемал — Панаевск. Для регулярных дней указана частота конкретного рейса в его интервале. Для отдельных дат и межсезонья частота пустая. Для Мужи — Горки объединены сведения двух рейсов, агрегированное число не определено. Нельзя переносить значения на другие месяцы; общая область этого экспорта октябрь–декабрь.

Прочитана доступная таблица вылетов из Салехарда. Остальные базы и водные линии этим проходом не покрыты. Поиск полного автобусного реестра через dtidh.yanao.ru не дал доступного документа. Старые заполненные частоты не переписывались; freq_fill.csv пуст. CSV разобраны, непустые ID проверены; тесты продукта не запускались.
