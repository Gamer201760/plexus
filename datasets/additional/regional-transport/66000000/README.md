# Смоленская область (66000000): межмуниципальные автобусы, второй проход

- Источник: официальный «Реестр межмуниципальных маршрутов регулярных перевозок Смоленской области» Министерства транспорта и дорожного хозяйства Смоленской области, файл [reestr-mezhmunicipal22.xlsx](https://mintrans.admin-smolensk.ru/files/295/reestr-mezhmunicipal22.xlsx) со страницы [«Автомобильный транспорт»](https://mintrans.admin-smolensk.ru/strukture/transport/avtomobilnyj-transport/) (скачан 2026-11-09). Реестр утверждён приказом от 27.03.2025 № 47, последняя редакция — приказ от 19.06.2026 № 136. Отсюда `source_date=2026-06-19`, а файл сохранён 2026-07-09. Оригинал и снимок страницы лежат в `raw/`.
- `bus_routes.csv`: 127 маршрутов, `confidence=high`. Раздел 1 реестра «Пригородное сообщение» дал 75 маршрутов с `route_kind=suburban`, раздел 2 «Междугородное сообщение» — 52 с `route_kind=intermunicipal`. Межрегиональных маршрутов в реестре нет. Строку маршрута № 123 реестр повторяет трижды, она сведена в одну. Под № 127 «Смоленск – Кощино» значатся два варианта с разными перевозчиками и путём, оба оставлены.
- `via` содержит промежуточные остановки прямого направления по реестру, без «По требованию». В `carrier` оставлены только наименования перевозчиков, без адресов и ИНН. У 11 маршрутов перевозчик в реестре не указан.
- Полнота сопоставления: оба конца найдены у 123 из 127 маршрутов, хотя бы один — у всех 127. Сопоставление шло по названию и проверялось по расстоянию: прямая между концами не длиннее протяжённости маршрута по реестру. Неоднозначные случаи разобраны по типу пункта в описании пути («д.», «с.», «п.»). Так, АРЗ — это п. Авторемзавод, а Понятовка — деревня, не станция.
- Ручные решения: № 147 «Смоленск – Рясино» отнесён к д. Рясино Кардымовского округа, потому что маршрут идёт по М-1 на восток через Семиречье, Буховку и Ковши. № 148 отнесён к д. Печерск по описанию пути. Оба решения пояснены в `schedule_note`.
- Без `to_id` остались четыре маршрута. Слободка (№ 105) и Черемушки (№ 141) — пригороды Смоленска, их нет во входном списке. Каспля (№ 160): во входе есть Каспля-1 и Каспля-2, а реестр их не различает. Сырокоренье (№ 215): у Десногорска есть только Старое и Новое Сырокоренье.
- `trips_per_week` пуст во всех строках. Реестр Смоленской области не содержит ни расписаний, ни числа рейсов, это отмечено в `schedule_note`. Сайт автовокзала с расписаниями не найден, а агрегаторы (Яндекс Расписания) не брались, чтобы не смешивать с официальным источником. `season` пуст по той же причине.
- `freq_fill.csv` содержит только заголовок: в первом проходе (`data_manual/regions/66000000.csv`) строк нет.
- `links_add.csv` содержит только заголовок. Повторный поиск паромов, понтонов и ледовых переправ нашёл только временную переправу МЧС у Велижа в ноябре 2014 г. ([МЧС](https://996sc.organizations.mchs.gov.ru/export/docx/Resource/158451)). Её уже разобрал первый проход: переправа внутри одного города. Регулярных авиарейсов нет: аэропорт «Северный» пассажиров не принимает, гражданский аэропорт только строится (см. первый проход).
- Отличие от первого прохода: первый собрал перечень труднодоступных пунктов Рославльского округа и не нашёл сезонных связей. Второй добавил полный официальный реестр межмуниципальных автобусов.
- Недоступно и ограничения: заголовок `Last-Modified` сайт не отдаёт, поэтому дата взята из шапки реестра. Протяжённость маршрута № 149 записана в реестре как «12, 1» и прочитана как 12,1 км. Муниципальные реестры не собирались.
