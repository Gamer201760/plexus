# Чеченская Республика (96000000): межмуниципальные автобусы, второй проход

- Источник: официальный реестр межмуниципальных маршрутов Министерства транспорта, связи и цифрового развития ЧР ([reestr01.xlsx](http://mtischr.ru/images/stories/novosti2026/reestr01.xlsx)). Ссылка размещена на странице «[Автомобильный транспорт](https://mtischr.ru/index.php?Itemid=572&id=+571&option=com_content&view=article)», проверено 2026-11-09. В самом файле даты нет. По метаданным xlsx файл изменён 2026-02-05, сервер отдаёт Last-Modified 2026-02-06; в `source_date` записано 2026-02-05. Файл и снимок страницы лежат в `raw/`.
- `bus_routes.csv`: 85 маршрутов с листа «межмуниципальные» (№ 100–227), `confidence=high`, `route_kind=intermunicipal`. Реестр не делит маршруты на пригородные и междугородные, межрегиональных маршрутов в нём нет.
- Оба конца сопоставлены у 82 из 85 маршрутов. Без id остались «60 лет Октября» (№ 103) и «Советская Россия» (№ 145, 204; в остановках указан «Винхоз Советская Россия», у № 204 последний остановочный пункт — Рубежное): во входном CSV таких н.п. нет.
- Сопоставление выполнено по названию с поправками на написание: Наур → Наурская, Долинск → Долинский, Катыр-Юрт → Катар-Юрт, Мехкеты → Махкеты, Серноводск → Серноводское. ТЦ Беркат, АС Южная и АВ Западный отнесены к Грозному. У названия «Аллерой» два н.п.; для № 175 и 221 выбран Аллерой Курчалоевского района, потому что маршрут идёт через Ойсхару и Нойбер. Для № 143 «Грозный — Чири-Юрт» в реестре указано 12,11 км, хотя по прямой между пунктами около 26 км. Название однозначно, поэтому id оставлен.
- `via` взят из графы «остановочные пункты», без первого и последнего пункта; префикс «ОП» убран. У № 109, 144, 204 и 211 средняя часть названия маршрута тоже добавлена в `via`.
- `trips_per_week` пуст у всех маршрутов: в реестре нет расписаний. Есть только максимальное число ТС, класс, вид тарифа и дата начала перевозок; это записано в `schedule_note`. Поиск расписаний автостанций (Беркат, Южная) и перевозчиков ничего официального не дал, нашлись только агрегаторы межрегиональных рейсов.
- Не включено: лист «Лист1» в том же файле. Это остаток шаблона с заголовком «…в городе Перми»; в нём смешаны городские маршруты и дубли межмуниципальных, а также маршрут Грозный — Кизляр без номера. Также не включён `reestr02.xlsx` с той же страницы, реестр муниципальных маршрутов: его собирать не нужно.
- `freq_fill.csv` содержит только заголовок: в `data_manual/regions/96000000.csv` первого прохода нет строк.
- `links_add.csv` содержит только заголовок. Первый проход не подтвердил местной авиации, зимников, паромов, понтонных и ледовых переправ. Для Чечни (юг, равнина и горы с круглогодичными дорогами) такой транспорт нетипичен, повторный поиск не проводился.
- Отличие от первого прохода: первый не нашёл сезонных связей и не собирал автобусы. Второй добавил полный официальный реестр межмуниципальных автобусных маршрутов.
- Блокеров нет: mtischr.ru отдал файлы без капчи и 403. Сайт Минавтодора ЧР (minavtodor-chr.ru) реестра перевозок не содержит.
