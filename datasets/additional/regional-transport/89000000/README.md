# Республика Мордовия (89000000): межмуниципальные автобусные маршруты, второй проход

- Реестр: «Реестр межмуниципальных маршрутов Республики Мордовия свод на 05.06» (xlsx, утверждён приказом Госкомтранса РМ от 21.01.2022 № 5, свод с изменениями). Опубликован на странице Госкомтранса РМ «Информация для граждан» (https://e-mordovia.ru/gosudarstvennaya-vlast-rm/ministerstva-i-vedomstva/goskomtrans/informatsiya-dlya-grazhdan/), файл: https://e-mordovia.ru/upload/iblock/ae8/glb5evd4emfzfvo4rrxsdk1l4bu5t0t9/Reestr-mezhmunitsipalnykh-marshrutov-Respubliki-Mordoviya-svod-na-05.06.xlsx. На сайте указана дата загрузки 01.09.2025, в метаданных файла стоит modified 2026-06-05. Отсюда source_date = 2026-06-05; в реестре есть контракты, выданные в сентябре 2025 г.
- Частоты взяты из официального «Расписания пригородных межмуниципальных маршрутов г.о. Саранск» Госкомтранса РМ (загружено 17.06.2025): https://e-mordovia.ru/upload/iblock/3f8/4e4d7c5fwzwb4267fttta6bkpyaz7gzd/Raspisanie.docx. Оригиналы и снимок страницы лежат в raw/.
- bus_routes.csv содержит 148 маршрутов: 90 пригородных (suburban) и 58 междугородных внутри республики (intermunicipal). Межрегиональных маршрутов в реестре нет. confidence = high.
- Сопоставление с н.п. выполнено с обоих концов для 146 из 148 маршрутов. Остаются пустыми: «Рузаевские дачи» (№ 137Д, дачный массив, во входе его нет) и «Козловка» (№ 243, 5 одноимённых сёл, по промежуточным пунктам выбрать нельзя). Порядок разрешения омонимов: подсказка района в названии → единственный районный центр среди кандидатов → район промежуточных остановок → совпадение расстояния с протяжённостью. «Вертилим» сопоставлен с с. Вертелим (разночтение в написании). Остановки внутри Саранска, включая «Психиатрическую больницу», отнесены к г. Саранск.
- trips_per_week заполнено для 62 маршрутов: это число отправлений от начального пункта в неделю по расписанию 2025-06. Если расписание делится на летнее и зимнее, в поле стоит зимнее значение, а оба числа указаны в schedule_note. № 103Л ходит по интервалу 5–20 мин, поэтому число отправлений не указано. Пять дачных маршрутов, помеченных в расписании «сезонный», получили season = summer; месяцы в расписании не указаны.
- Не найдено: расписания почти всех междугородных маршрутов (5xx). Официальное расписание охватывает только пригородные маршруты Саранска, а сайт АО «Объединение автовокзалов и автостанций» не нашёлся. Яндекс.Расписания отдают страницу без рейсов (JS), их не использовали. У 41 маршрута в реестре не указан перевозчик; возможно, сейчас они не обслуживаются (это отмечено в schedule_note).
- Доступ: e-mordovia.ru закрыт JS-проверкой с cookie (__js_p_/__jhash_) и сертификатом Минцифры, поэтому WebFetch не работает. Файлы скачаны скриптом, который решает проверку.
- freq_fill.csv пуст (только заголовок): в первом проходе нет строк без частоты. links_add.csv тоже пуст: местной авиации, зимников, паромов, понтонных и ледовых переправ в источниках нет. Поиск 2026-11 подтвердил вывод первого прохода (см. data_manual/regions/89000000.md). Прогулочный теплоход «Край Земли» в Ардатове транспортной связью не считается.
- Отличие от первого прохода: в первом проходе не было ни одной связи. Здесь добавлен официальный реестр автобусных маршрутов с км, промежуточными остановками, перевозчиками и частотой для пригородной сети Саранска.
