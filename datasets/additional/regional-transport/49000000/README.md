# Новгородская область (49000000): межмуниципальные автобусы, второй проход

- Источник: официальный «Реестр межмуниципальных маршрутов регулярных перевозок пассажиров и багажа автомобильным транспортом общего пользования Новгородской области на 01.10.2026» (приложение 1 к приказу министерства транспорта и дорожного хозяйства от 30.08.2024 № 159). Файл со страницы [mintrans.novreg.ru/activity/automobile](https://mintrans.novreg.ru/activity/automobile/), проверено 2026-11-09. Оригинальный `.xls` и снимок страницы лежат в `raw/`. Реестр опубликован одним файлом.
- `bus_routes.csv`: 169 маршрутов, `confidence=high`, `source_date=2026-10-01`. Из них 116 идут по регулируемым тарифам (все не длиннее 50 км), 53 по нерегулируемым. Реестр не делит маршруты на пригородные и междугородные, поэтому у всех стоит `route_kind=intermunicipal`. Межрегиональных маршрутов в реестре нет.
- Сопоставление: оба конца найдены у 156 из 169 маршрутов, хотя бы один конец у всех 169. Неоднозначные названия разрешены по списку остановок в реестре и по расстоянию; так определены Подберезье, Дубровка, Нащи, Спас-Нередицы, Устье, Лесная, Старина, Ермолино. Без id остались: дачи и садовые массивы (Мшагские, Фарафоновские, Вашковские, Горыневские дачи, «Заречный — Сады»), «Кладбище», «Турбаза Глебово», а также Каменка, Заозерье, Горки и Новая Деревня. Для последних в области есть несколько одноимённых деревень, а реестр не даёт остановок, по которым можно выбрать одну.
- `trips_per_week` заполнен у 122 маршрутов. Его посчитали по листу «Расписание» реестра: дни отправления × число рейсов, отправления из начального пункта, расписание зимнего сезона. Если рейсы указаны только из конечного пункта, считались они; это отмечено в `schedule_note`. Летнее значение и обратное направление тоже приведены в `schedule_note`, если отличаются. `season=summer` стоит у 5 маршрутов, у которых есть только летнее расписание, `winter` у одного с зимним.
- Без частоты остались 47 маршрутов. У 43 расписание в реестре не заполнено; ни у одного из них не указан и перевозчик (всего без перевозчика 58 маршрутов). У 3 маршрутов рейсы ходят раз в две недели («1-я и 3-я пятница», «2-й и 4-й понедельник»), в целое число рейсов в неделю это не переводится. У маршрута 187 «Станция Нащи» сдвинуты колонки летнего расписания. По многим маршрутам в реестре стоят пометки «проводятся конкурсные процедуры» и «перевозки не осуществляются», а сроки ряда свидетельств уже истекли. Всё это перенесено в `schedule_note`: реестр не значит, что рейсы сейчас выполняются.
- `freq_fill.csv` содержит только заголовок: у единственной строки первого прохода (Великий Новгород — Взвад, river) частота уже заполнена.
- `links_add.csv` содержит только заголовок. На странице министерства «Водный транспорт» сказано, что в навигацию действует единственный пригородный водный маршрут Великий Новгород — Взвад, а он уже есть в первом проходе. Раздел «Воздушный транспорт» содержит только историческую справку о местных авиалиниях до 2004 года. Поиск паромов, понтонных и ледовых переправ нашёл только временную объездную переправу на время ремонта моста через Вотросу (Пестовский округ, 2025). Связью между населёнными пунктами она не является.
- Отличие от первого прохода: первый собрал одну речную линию и перечень труднодоступных пунктов, второй добавил полный официальный реестр межмуниципальных автобусов с частотами из встроенного расписания.
- Ограничения: id сопоставлены по названию и координатам входного справочника. У маршрутов «В. Новгород — Нащи» и «В. Новгород — Дубровка» расстояние по прямой между точками справочника на 15–20% больше протяжённости по реестру; сопоставление оставлено, потому что его подтверждают остановки в реестре. Муниципальный реестр Великого Новгорода с той же страницы не собирался.
