# Курганская область (37000000): межмуниципальные автобусы, второй проход

- Источник: официальный реестр межмуниципальных маршрутов Департамента экономического развития Курганской области (отдел транспорта). Файл `reestr_20261103.xlsx` взят со страницы [economic.kurganobl.ru/6722.html](http://www.economic.kurganobl.ru/6722.html), проверено 2026-11-09. Ссылка на файл: http://www.economic.kurganobl.ru/assets/files/transport/regular/reestr_20261103.xlsx. Оригинал и снимок страницы лежат в `raw/`. Сайт отдаёт страницы в cp1251, без блокировок.
- В `bus_routes.csv` 94 действующих маршрута, у всех `confidence=high` и `source_date=2026-11-03`. В реестре 105 строк, из них 11 исключены: в графе «Даты вынесения решения об отмене маршрута» у них стоит распоряжение 2024–2026 гг. Это 113 Шадринск – Коврига, 507 (одна из трёх строк), 522 Мишкино, 535 Камаган, 555 Шадринск – Далматово, 574 (одна из двух), 579 Частоозерье, 715 Альменево, 255 Введенское – Кетово, 512 Усть-Уйское, 572 Варгаши. По одному номеру маршрута бывает несколько строк реестра (разные перевозчики или варианты пути). Ключ строки — регистрационный номер.
- В реестре нет деления на пригородные и междугородные маршруты, поэтому у всех строк `route_kind=intermunicipal`. Межрегиональных маршрутов в реестре нет.
- Оба конца сопоставлены у 84 из 94 маршрутов; хотя бы один конец — у всех 94. Остановки Кургана (автовокзал, «Курган АВ», вокзал, Пригородный вокзал, Троицкая площадь, Художественный музей, Святодуховский сквер, Школа № 18) и Шадринска (ж/д вокзал, КП, ШААЗ, электродный завод) сопоставлены с городом. Город определён по графе «улицы» реестра. «КП <район>» сопоставлены с райцентром, КГСХА — с с. Лесниково, где она находится по графе улиц. Без id остались д/о «Сосновая Роща» (2 маршрута), д/о «Лесники» (2), пять садовых массивов («Космос», «Полянки», «Иволга», «Патронное», «Икчанка») и п. Озёрный (маршрут 233). Каждое сопоставление проверено расстоянием: прямая между концами не длиннее протяжённости по реестру; нарушений нет.
- `trips_per_week` заполнен у всех 94 маршрутов. Значение посчитано по листам расписаний внутри xlsx (по одному листу на строку реестра): число отправлений из начального пункта в прямом направлении × число дней недели, просуммированное по всем графикам основного периода. Рейсы, которые начинаются с промежуточного пункта, рейсы другого периода и отдельное «летнее расписание» в сумму не входят и перечислены в `schedule_note`.
- `season`: 89 маршрутов работают круглый год (`all`), 5 садовых маршрутов Кургана — `summer` (апрель–октябрь). У маршрута 574 Ошурково зимнее и летнее расписания разные (3 и 5 рейсов в неделю). У маршрута 121 Белозерское расписание тоже разделено на зимнее и летнее, по 27 рейсов в неделю в каждом.
- В реестре все названия набраны с подменой букв: латинские a/o/M/T и греческая ο вместо кириллицы. В CSV они заменены кириллицей. Протяжённость «29 1» прочитана как 29,1 км. Где в реестре две протяжённости (прямое/обратное направление), `km` пуст, а значения записаны в `schedule_note`. В `carrier` записано только наименование перевозчика, без ИНН, адресов и e-mail.
- Действующих маршрутов с конечным пунктом в райцентрах Альменево и Частоозерье в реестре нет: их маршруты 715 и 579 отменены 29.10.2024. Звериноголовское, Глядянское, Далматово, Лебяжье, Мишкино и Щучье встречаются только как промежуточные пункты.
- `freq_fill.csv` содержит только заголовок. У трёх строк первого прохода (ледовая тропа и лодка Утятское – Нагорское, понтон у д. Лаптева) частот нет ни в одном источнике. В статье [rg.ru, 2025-01-29](https://rg.ru/2025/01/29/reg-urfo/razvela-pereprava.html) есть только «организовали лодочную переправу» и «ходят по ледовой переправе», без расписания. Сведений о восстановлении обоих мостов в 2025–2026 гг. поиск не дал.
- `links_add.csv` содержит только заголовок. Новых сезонных связей (местная авиация, зимники, речные линии, паромы, понтоны, ледовые переправы) не найдено. Это согласуется с первым проходом: равнинный регион, сообщение автомобильное.
- Отличие от первого прохода: первый собрал три сезонные переправы через Тобол и перечень труднодоступных сёл. Второй добавил полный официальный реестр межмуниципальных автобусов с частотами из встроенных расписаний.
- Ограничения: частота — плановая, по расписанию реестра; фактическое выполнение рейсов не проверялось. Муниципальные реестры округов (например, Куртамышского) не собирались.
