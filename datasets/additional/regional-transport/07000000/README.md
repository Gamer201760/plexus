# Ставропольский край (07000000) — межмуниципальные автобусы, второй проход

- Источник: официальный реестр межмуниципальных маршрутов министерства дорожного хозяйства и транспорта Ставропольского края, файл «Реестр межмуниципальных маршрутов 2 ноября 2026 года (для размещения).xlsx» со страницы [dorogisk.ru/transport/reestr-marshrutov](https://dorogisk.ru/transport/reestr-marshrutov/) (проверено 2026-11-09). Оригинал и снимок страницы лежат в `raw/`.
- `bus_routes.csv`: 343 маршрута, `confidence=high`, `source_date=2026-11-02`. Ещё 35 строк реестра несут только регистрационный номер без маршрута (выбывшие номера), они не включены. Все маршруты получили `route_kind=intermunicipal`: реестр не делит их на пригородные и междугородные. Межрегиональных маршрутов в реестре нет.
- Сопоставлены оба конца у 334 из 343 маршрутов; хотя бы один конец сопоставлен у 342. Без id остались: Садовый (у Пятигорска; в описании пути указано «с. Садовое», есть одноимённый хутор), Горный (у Ессентуков, два посёлка), Пролетарская Воля, Верхняя Дубовка, Верхняя Татарка, конечная «Ставрополь - Верхнерусское». Соответствия «Дубовая Роща» нет: во входе есть только одноимённый посёлок Александровского округа в 72 км, а протяжённость маршрута 22 км.
- Совпадение названий проверено расстоянием: если расстояние по прямой между концами больше протяжённости по реестру, сопоставление отброшено.
- `trips_per_week` заполнен у 266 маршрутов. Значение посчитано по расписаниям, встроенным в реестр как OLE-объекты (347 штук). Расписание привязано к строке по паре «регистрационный номер + порядковый номер», а не по положению значка: значки часто сдвинуты. Считаются отправления из начального пункта по всем графикам, умноженные на число дней недели. У 44 маршрутов в реестре стоит «временно не обслуживается», частота не дана. У 33 маршрутов расписание не найдено или не разобрано; это указано в `schedule_note`.
- `season=all` стоит там, где во всех строках расписания указан период «с 1 января по 31 декабря». Сезонных межмуниципальных автобусных расписаний в реестре нет.
- `freq_fill.csv` содержит только заголовок: в первом проходе (`data_manual/regions/07000000.csv`) не было строк для заполнения.
- `links_add.csv` содержит только заголовок. Местную авиацию, зимники, речные линии и паромы проверил первый проход; повторный поиск переправ нашёл только временный объезд на время ремонта Сиушкина моста в с. Китаевском. Это переезд внутри села, а не связь между пунктами.
- Отличие от первого прохода: первый собрал перечень труднодоступных пунктов и не нашёл сезонных связей. Второй добавил полный официальный реестр межмуниципальных автобусов с частотами.
- Ограничения: у dorogisk.ru сертификат НУЦ Минцифры, поэтому файл скачан с отключённой проверкой TLS. Скачивание медленное (около 7,5 МБ за несколько минут). Муниципальные реестры (троллейбусы Ставрополя, Пятигорск), которые лежат на той же странице, не собирались.
