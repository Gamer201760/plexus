# Пензенская область (56000000) — второй проход

- Реестр межмуниципальных маршрутов регулярных перевозок от 16.10.2026, Минстрой Пензенской области: страница https://minstroy.pnzreg.ru/taill/avtobusnye-marshruty-regulyarnykh-perevozok-passazhirov/reestry-munitsipalnykh-i-mezhmunitsipalnykh-marshrutov-regulyarnykh-perevozok-passazhirov/ (открыта 2026-11-09). Оригинал: `raw/reestr_mezhmun_2026-10-16.xlsx`, один лист, 174 строки. Муниципальные реестры Пензы, Заречного и Пензенского района на той же странице не брались.
- `bus_routes.csv`: 126 маршрутов (по одной строке на регистрационный номер). Если у номера несколько перевозчиков (157, 540, 604, 607), их имена перечислены через «; », а отправления сложены. Все строки имеют confidence=high и source_date=2026-10-16.
- В реестре нет поля «пригородный/междугородный». route_kind выведен из протяжённости по правилу Устава автотранспорта: до 50 км включительно — suburban (80), больше — intermunicipal (46). Межрегиональных маршрутов в реестре нет.
- Оба конца сопоставлены у 115 из 126 маршрутов, у действующих — у 110 из 119. Без id остались конечные пункты Кузнецк-8 и Кузнецк-12 (их нет во входе), ТЦ «Ритейл Парк», ул. Зеленодольская, дачные объекты маршрутов 205–208 и с. Аблязово (маршрут отменён).
- Ручные сопоставления по трассе из реестра описаны в schedule_note: «п.Мичурино» → п. Мичуринский, «с.Андреевка» → Старая Андреевка, «с.Турдаки» → Старые Турдаки, «с.Демкино» → Старое Демкино, Зареченская птицефабрика → Кижеватово, з-д «Беском» → Бессоновка.
- В 7 строках реестр указывает «маршрут отменён» или «не обслуживается» (120, 150, 158, 274, 281, 588, 610). У них carrier и trips_per_week пусты, season не заполнен.
- trips_per_week заполнен у 111 маршрутов. Это отправления из начального пункта за неделю по расписанию, встроенному в реестр: рабочие дни ×5, выходные ×2, по дням недели — как указано. У сезонных маршрутов значение взято для периода, действующего в ноябре; летнее значение приведено в schedule_note. Списки времён без указания дней считались ежедневными; это отмечено в schedule_note.
- 8 дачных маршрутов Заречного (201–208) имеют season=summer и действуют с мая по октябрь. Число рейсов в них меняется по периодам и не суммировалось. Маршрут 105 обслуживает троллейбус; он оставлен, потому что входит в реестр.
- freq_fill.csv пуст. Единственная строка первого прохода — понтон Засечное — Пенза; для моста частота рейсов неприменима. Новых датированных сведений о режиме понтона не нашлось: на https://pnz.ru/tag/pontonnyj-most/ (2026-11-09) сообщение о закрытии не имеет даты.
- links_add.csv пуст. Новые понтоны, паромы, зимники, ледовые переправы и местная авиация в поиске не найдены. Для центра России это ожидаемо; отсутствие найденных данных не доказывает отсутствие таких связей.
- Блокеров нет: сайт минстроя отдал страницу и xlsx без капчи. Домен mintrans.pnzreg.ru не резолвится. Отличие от первого прохода: в первом проходе автобусная сеть не собиралась, теперь добавлен полный официальный реестр.
