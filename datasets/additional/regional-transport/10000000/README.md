# Амурская область (10000000) — второй проход: автобусный реестр и дополнения
- Реестр: «Реестр межмуниципальных маршрутов регулярных перевозок Амурской области по состоянию на 01.08.2026», Минтранс Амурской области, [страница реестра](https://mintrans.amurobl.ru/pages/avtomobilnyy-passazhirskiy-transport2/reestr-mezhmunitsipalnykh-marshrutov-regulyarnykh-perevozok-amurskoy-oblasti/), [XLS](https://mintrans.amurobl.ru/upload/iblock/394/3ikq80mhm2gm7f9qp3zkmz6w7cdyqjmy.xls); оригинал — `raw/reestr_mezhmun_2026-08-01.xls`. Сайт за DDoS-защитой, файл скачан с cookie, полученными после проверки в браузере.
- `bus_routes.csv`: 85 маршрутов (53 intermunicipal, 32 suburban; suburban — номера серии 1xx до 50 км), все confidence=high, source_date=2026-08-01.
- Сопоставление: 84/85 маршрутов сопоставлены с н.п. входа с обоих концов; не сопоставлен конец «п. Первомайский» (№136 Тында — Первомайский): во входе такого названия нет.
- Промежуточные пункты (`via`) взяты из листа «маршруты», оставлены только названия, найденные во входе; повороты и остановки отброшены.
- `trips_per_week` выведена для 46 маршрутов из сводного расписания внутри того же XLS (отправления в прямом направлении: ежедневно ×7, будни ×5 и т.п.); для остальных пусто, причина в `schedule_note`. Перевозчики — лист «перевозчики», «открытый конкурс» вынесен в примечание.
- `freq_fill.csv`: 1 из 5 пустых частот — Благовещенск — Хэйхэ (river) = 28/нед. (4 рейса в день, навигация 2024) по [EastRussia, 03.05.2024](https://www.eastrussia.ru/news/vozobnovilis-passazhirskie-perevozki-mezhdu-blagoveshchenskom-i-kheykhe/).
- Не заполнены: наплавной мост Благовещенск — Хэйхэ (Росгранстрой даёт только часы работы 08:00–21:00, не число рейсов), ледовые переправы Ураловка — Кухтерин Луг и Усть-Нюкжа — Юктали, зимник Верхнезейск — Бомнак: у переправ и зимников нет расписания, источник частоты не найден.
- `links_add.csv`: новых связей нет (только заголовок). Проверить не удалось: зимнее расписание «Авроры» 2025/26 на Тынду/Зею, рейсы в Экимчан, паромы через Зею/Селемджу, СВП Благовещенск — Хэйхэ в межсезонье (тот же ключ from/to/mode=river, отдельной строкой не добавлен).
- Блокеры: mintrans.amurobl.ru и портал открытых данных отдают DDoS-заглушку для curl; исчерпан лимит веб-поиска/загрузок сессии до завершения задач 2–3, поэтому поиск авиации и переправ прерван — это пробел поиска, не доказательство отсутствия связей.
- Отличие от первого прохода: первый собрал только сезонные связи (16 строк: авиация, переправы, теплоход); автобусный межмуниципальный реестр добавлен впервые.
