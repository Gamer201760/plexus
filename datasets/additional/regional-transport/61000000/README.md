# Рязанская область (61000000): второй проход, транспортная связанность

- Главный источник: официальный «Реестр межмуниципальных маршрутов регулярных перевозок на территории Рязанской области» Минтранса и автодорог Рязанской области, актуален на 12.10.2026 ([XLS](https://mintrans.ryazan.gov.ru/upload/iblock/b71/cb5gcvgh1sgampermbv99us754lcsbhi/REESTR-MARSHRUTOV-na-12.10.2026-g.xls), раздел [«Информационные системы, реестры»](https://mintrans.ryazan.gov.ru/documents/informatsionnye_sistemy_reestry/)). Оригинал лежит в `raw/`. Рядом сохранено сводное расписание межмуниципальных автобусов на 07.08.2026 (DOC). В разбор оно не вошло, потому что расписания уже есть в листах реестра.
- `bus_routes.csv`: 90 строк, по одной на регистрационный номер. Это 71 номер маршрута, подлоты разных перевозчиков (например, 33.1/33.2/33.3) записаны отдельными строками. Все строки имеют `route_kind=intermunicipal` и `confidence=high`. Межрегиональных маршрутов реестр не содержит.
- Оба конца сопоставлены с входными н.п. у 88 из 90 строк (98%). Без `to_id` остались №123 «Победа» (совхоз «Победа», которого нет во входном списке) и №130 «Батурино» (во входе есть и Новое, и Старое Батурино). Нечёткие сопоставления описаны в `schedule_note`: «Зимино» → с. Старое Зимино, «Смена» → пос. совхоза «Смена».
- `trips_per_week` посчитан по листам «Расписание N» реестра. Это отправления в прямом направлении в основном периоде (круглогодичном или зимнем). Значения обратного направления и летнего периода записаны в `schedule_note`. Поле заполнено у 86 из 90 строк. Пусто у №144 и №241 (интервальное движение без числа рейсов), №184 (лист расписания пуст) и №592 (неоднозначные дни третьего рейса).
- Ячейки дней в реестре многострочные. У №118 (4.2), №129, №153, №171 и №528 разбивка по рейсам прочитана вручную, пояснение дано в `schedule_note`.
- Сезонность по реестру: №139 Спасск—Юшта ходит только с 01.12 по 30.04 (`winter`). №157 Криуша—Шехмино ходит с 15.04 по 14.11, по пт и вс (`summer`). №513 (47.2) ходит по субботам с 15.04 по 01.10 (`summer`).
- `freq_fill.csv` содержит только заголовок. Единственная строка первого прохода без частоты — наплавной мост Спасск—Фатьяновка, и частота к мосту неприменима.
- `links_add.csv` содержит только заголовок. Новых подтверждённых сезонных связей (air, winter_road, ferry, ice_crossing, pontoon_bridge) с известными берегами не найдено. Регулярной местной авиации в регионе нет. Поиски переправы у Криуши/Шехмино, ледовых переправ 2026 года и берегов понтона у Троицы источников не дали. Переправы у Юшты, Елатьмы и Троицы по-прежнему не привязаны (см. `data_manual/regions/61000000.md`).
- Доступ: у `*.ryazan.gov.ru` цепочка сертификатов не проходит стандартную проверку (самоподписанный корень, вероятно НУЦ Минцифры), файлы скачаны с `curl -k`. Других блокировок (403, капчи) не было. Поддомены `mtad.`/`minrt.ryazan.gov.ru` отдают «Страницы не существует».
- Отличие от первого прохода: первый проход собрал только сезонные связи (2 паводковые линии теплохода и наплавной мост). Второй проход добавил полный официальный реестр межмуниципальных автобусных маршрутов с частотами, перевозчиками и промежуточными пунктами.
