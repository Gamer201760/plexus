# Кировская область (33000000): второй проход, регулярные автобусы

- Реестр межмуниципальных маршрутов по 220-ФЗ в открытом виде не найден. На сайте Минтранса области https://transport.kirovreg.ru/ (проверено 2026-11-09) раздела с реестром нет. Разделы «Открытый конкурс», «Процедура определения перевозчиков» и «Информация о принятых решениях» пусты, веб-поиск реестр тоже не нашёл.
- Основной источник — официальный перечень Минтранса «ОТОП на 01.12.2021 табл.csv» (отчёт сформирован 03.07.2020): https://transport.kirovreg.ru/upload/iblock/e40/706sg4odcmiliwxktl8wr0tw5lrx708x.csv . Ссылка на него стоит на странице https://transport.kirovreg.ru/activity/transport_complex/car/intermunicipal-bus-schedule/ . Это сведения об остановках межмуниципальных маршрутов: номер, наименование и упорядоченный список остановок с адресами. Сохранён в `raw/`.
- `bus_routes.csv`: 95 маршрутов (маршрут 125 повторялся в источнике трижды, дубли удалены). Поставлены confidence=high и source_date=2021-12-01. Перечень официальный, но устарел: изменения 2022–2026 годов в нём не отражены.
- route_kind определён по нумерации. Номера 1xx и маршруты Кирово-Чепецка «…КЧ» — suburban, их 53; номера 2xx — intermunicipal, их 42. Так же Кировский автовокзал делит рейсы на «пригородные» и «междугородные» (kirovkpat.ru).
- Оба конца сопоставлены с н.п. входного CSV у 94 из 95 маршрутов. Не сопоставлен один конец: с/т «Чистые Ключи» (№120). У 7 маршрутов конец сопоставлен по адресу конечной остановки: Шинник-6 и «Энергетик» → д. Шунки, Вятские Увалы → с. Бурмакино, д/о «Кстининский» → с. Кстинино, с/х «Березниковский» → с. Березник, сады «Сунчиха» → д. Сунчиха, с/т «Содружество» → г. Киров. Одноимённые пункты (Цепели, Полом, Васькино, Ильинское, Чуваши, Яранск и др.) разведены по району из адресов остановок; это отмечено в schedule_note.
- via взят только из промежуточных пунктов в названии маршрута. km, carrier и trips_per_week в источнике отсутствуют, поэтому пустые. season=all ставится у несезонных маршрутов; у 8 маршрутов с пометкой «(сезонный)» season пустой, потому что период не указан.
- Для справки в `raw/` сохранены текущие расписания АВ Киров (АО «КировПассажирАвтотранс»): https://kirovkpat.ru/mezhdugorodnym-marshrut и https://kirovkpat.ru/prigorod-marshrut (пригородные, «зима 2026–2027, с 12.10.2026»). Частоты из них не выведены: отметки дней («кр.вс.», «р.д.», «пт.» и т.п.) неоднородны. Новые маршруты (237 Афанасьево, 242 Великорецкое и др.) не добавлены.
- `freq_fill.csv` пустой. Единственная строка первого прохода — наплавной мост Светлаковы — Часовня, для него частота неприменима.
- `links_add.csv` пустой. Минтранс (https://transport.kirovreg.ru/activity/transport_complex/water/, 2026-11-09) пишет, что пассажирских перевозок по воде нет, только прогулочные. В области один аэропорт (Победилово), внутриобластных авиалиний нет.
- Найдены наплавные мосты у с. Гоньба через Вятку (дорога Казань — Пермь; разведён 01.04.2026, работает с 31.05.2026: https://nta-pfo.ru/news/jkh/2026/news_739744/ , https://www.mk-kirov.ru/social/2025/12/29/dvizhenie-po-pontonnomu-mostu-v-malmyzhskom-rayone-vosstanovleno.html) и у пгт Лальск через Лузу (разведён 01.04.2026). Строки не созданы: н.п. на противоположном берегу источники не называют. Гоньба и Малмыж оба на правом берегу.
- Ледовые переправы и зимники 2025–2026 с установленными концами поиском не найдены. Википедия (API) часть запросов отклоняла.
