# Республика Алтай (84000000): региональный транспорт, второй проход

- Реестр ведёт Министерство транспорта и дорожного хозяйства РА (Минтранс РА, с 01.01.2025), сайт https://mintrans-ra.ru, раздел «Перевозки по межмуниципальным маршрутам» (/region/taransport/perevozki-po-mezhmunitsipalnym-marshruta.php, проверено 2026-11-09). Старый домен Минрегиона minregion-ra.ru не резолвится.
- `raw/prikaz_20260903_L-23-01-143.pdf`: приказ Минтранса РА от 03.09.2026 № Л-23-01/143, реестр межмуниципальных маршрутов в новой редакции. Это основной источник, source_date 2026-09-03. `raw/reestr_mezhmun_ra_20260403.pdf`: предыдущая редакция от 03.04.2026. Номера маршрутов в обеих редакциях одни и те же (40 записей).
- `bus_routes.csv`: 39 маршрутов, все confidence high. Маршрут 126 записан в реестре дважды, по разу на каждого ИП-перевозчика, здесь эти записи объединены в одну строку. 27 маршрутов `suburban` (№ 100–218: Горно-Алтайск — Майма/Кызыл-Озёк/Алферово/Соузга/Урлу-Аспак/Озерное/Подгорное). 12 маршрутов `intermunicipal` (№ 550–612: из Горно-Алтайска в Шебалино, Усть-Кан, Онгудай, Улаган, Тюнгур, Турочак, Каракокшу, Кош-Агач, Чёрный Ануй, Озеро-Куреево, Чемал, Артыбаш). Деление на пригородные и междугородные сделано по нумерации и длине маршрута: в самом реестре такой графы нет. Межрегиональных маршрутов в реестре нет.
- Сопоставление: у 38 из 39 маршрутов оба конца сопоставлены с н.п. входного файла. Не сопоставлен один конец: у маршрута 103 конечный пункт «Аэропорт» (аэропорт Горно-Алтайск). Поле via заполнено населёнными пунктами из реестра: для междугородных маршрутов из графы остановочных пунктов, для пригородных из графы улиц и дорог.
- trips_per_week есть у 6 междугородных маршрутов: 560, 569, 579, 580, 584, 610. Это отправления из Горно-Алтайска по расписанию автовокзала на e-traffic.ru (`raw/etraffic_avtovokzal_gorno-altaysk_2026-11-09.html`, достоверность расписания medium). Для 611 (Чемал) и 612 (Артыбаш) на автовокзале несколько рейсов разных перевозчиков, по маршрутам реестра их не разнести, поэтому рейсы перечислены в schedule_note. Рейсов на Кош-Агач, Улаган, Шебалино и Чёрный Ануй в расписании нет. У маршрутов 550, 578, 590 и 612 в реестре не указан перевозчик.
- Пригородные: Минтранс РА ссылается на графики РОО «ГАГСИП» РА (soyuz04.ru, файл от 09.11.2025, `raw/soyuz04_graf_prigorod_2025-11-09.htm`). Графики составлены на каждый выпуск (автобус), режим выходных в них неполный, поэтому рейсы в неделю не выведены. В schedule_note указано только число выпусков.
- `freq_fill.csv` (1 строка): автопаромы Артыбаш — южный берег Телецкого озера. Летом ходят ежедневно (7 рейсов в неделю), в мае и сентябре несколько раз в неделю; источник privet-altai.ru, обновлено 23.03.2025, время рейсов по paromnateletskom.ru. Для катера Артыбаш — Яйлю расписания не нашлось.
- `links_add.csv` (2 строки): Озеро-Куреево — Каначак через Бию. Ледовая переправа (`ice_crossing`) по данным МЧС РА (tolknews.ru, 02.02.2026), летом лодочная переправа (`ferry`) «ежедневно, кроме воскресенья» по ru.wikipedia (confidence low).
- Не добавлены ледовые переправы, у которых известен только один берег: Барангол (Катунь), Красноярка (Кокса), Катанда (Катунь), Дайбово/Дмитриевка (Бия), Инегень и Малый Яломан (Катунь), Суранаш (Лебедь). Источники: МЧС РА 2022–2026, gochsra.ru, tolknews.ru.
- Местная авиация: подтверждения рейсов в Кош-Агач и Усть-Коксу в 2025–2026 нет. Коммерсантъ (kommersant.ru/doc/5329400, 2022) сообщал о новой приостановке полётов «СиЛА». Субсидируемые рейсы 2026 года из Горно-Алтайска только межрегиональные. Зимников, понтонных мостов и регулярных речных линий не найдено.
- Отличие от первого прохода: добавлены официальный реестр автобусных маршрутов, частота паромов на Телецком озере и переправа на Каначак. Строки air первого прохода не менялись.
