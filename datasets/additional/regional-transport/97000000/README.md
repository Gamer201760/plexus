# Чувашская Республика (97000000): региональный транспорт, второй проход

- Реестр: «Реестр муниципальных и межмуниципальных маршрутов регулярных перевозок автомобильным транспортом Чувашской Республики» на 30.10.2026, Минтранс Чувашии. Страница: https://mintrans.cap.ru/action/activity/transportnij-kompleks-chuvashskoj-respubliki/avtomobiljnij-transport-chuvashskoj-respubliki/avtomobiljnij-transporta-chuvashskoj-respubliki/http-mintranscapru-action-activity-transportnij-ko , файл: https://fs.cap.ru/file/eed98342d8db42d489ef58926f656ebc (`raw/reestr_marshrutov_2026-10-30.xlsx`). Взят только лист «межмуниципальные», лист «муниципальные» (Чебоксары, Новочебоксарск) не использован.
- Расписание Минтранса на 29.10.2026: https://fs.cap.ru/file/28c8aa2f71d4462d81f54cd99637a518 (`raw/raspisanie_marshrutov_2026-10-29.xlsx`). Из него взято `trips_per_week` — число отправлений из начального пункта за неделю. Время без отметки дней считается ежедневным, отметки вида (1-5) и (6,7) учтены по числу дней. Интервальные, сезонные, «существующее положение / с даты» и прочие сложные записи не считались, их текст лежит в `schedule_note`. Частота посчитана для 118 из 176 маршрутов.
- `bus_routes.csv`: 176 автобусных маршрутов. Рег. № с префиксом «МГ» (междугородные) — intermunicipal (69), остальные — suburban (107). Три межмуниципальных троллейбусных маршрута (№60, 61, 62, Новочебоксарск — Чебоксары) исключены. Строки реестра с дополнительным перевозчиком (пустое название) присоединены к маршруту выше. Варианты с другим названием под тем же рег. № записаны отдельными строками. Сезонные (summer): 4.
- Сопоставление: у 165 из 176 маршрутов оба конца сопоставлены с н.п. входного CSV. Автовокзалы, ДКП и остановки отнесены к своему городу. Тёзок различали по району в списке остановок реестра, по соседним остановкам или по протяжённости (способ записан в `schedule_note`). «Конары» сопоставлены с пос. Конар. Один конец пуст у 11 маршрутов: сады Сутчево, к/с «Союз», т/к «Волжанка», Шешкары (пристань), к/с «Шоркино», к/с «Энергия», Новинское, СПК «Волга» (нет в справочнике), Ойкасы (№265, два тёзки в Чебоксарском районе), д. Ильбеши (два тёзки), Большие Шептаки (в справочнике только «Шептаки»).
- `freq_fill.csv` пуст. «Валдай» Чебоксары — Свияжск: порт публикует только тур с отправлением в 08:00 (`raw/chport_sviyazhsk_tour_2026-11-09.html`), дней недели нет. «Водолёт» Казань — Мариинский Посад — Чебоксары — Козьмодемьянск: на странице рейсов https://tickets.vodoletnn.ru/route/2255/view в ноябре «Нет данных» (навигация закрыта). Для понтонного моста и ледовой переправы частота неприменима.
- `links_add.csv`, 1 строка: авиарейс Чебоксары — Минеральные Воды (Азимут, ср и сб, 2 в неделю, c 31.03.2026 по 27.03.2027), по расписанию аэропорта https://aerocheb.ru/passazhiram/raspisanie/ на 2026-11-09. Маршрут числился в региональном перечне субсидируемых (отбор Минтранса Чувашии, июнь 2024, `raw/mintrans_air_subsidy_otbor_2024.html`). Субсидию 2026 года подтвердить не удалось. Второй субсидируемый маршрут, Чебоксары — Махачкала, в текущем расписании аэропорта отсутствует и не добавлен. Местной авиации внутри республики, зимников и паромов в просмотренных источниках не нашлось.
- Доступность: сайты *.cap.ru без браузерного User-Agent сбрасывают соединение, часть запросов прошла только с повторов. Лимит веб-поиска сессии исчерпан после 2 запросов. Поэтому дальше шли только переходами по сайтам Минтранса, порта, аэропорта и «Водолёта», а паромы, понтонные мосты на Суре и прочие сезонные связи дополнительно не искались.
- Отличие от первого прохода: там было 8 сезонных связей (речные рейсы, наплавной мост и ледовая переправа у Шумерли) без автобусной сети. Теперь добавлены все межмуниципальные автобусные маршруты из официального реестра 2026 года с частотами из официального расписания и субсидировавшийся авиарейс в Минеральные Воды.
