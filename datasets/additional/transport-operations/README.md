# Расписания и исходные транспортные документы

Архив получен 07.11.2026. `sources.json` содержит все уникальные URL из транспортных CSV регионального сбора и дополнительную подборку официальных расписаний, сообщений МЧС и муниципального конкурсного задания. `manifest.jsonl` сохраняет каждую попытку получения: URL, фактический адрес после перенаправления, время, HTTP-статус, размер и SHA256. При нескольких попытках итоговой считается последняя. Числа результата — в `profile.json`.

Файлы находятся в `data/additional/transport-operations/`, имя — первые 20 знаков SHA256 исходного URL. HTML/PDF сохранены без изменения. Рядом лежат текстовые извлечения; для PDF номер страницы начинается с 1. Успешное HTTP-получение не подтверждает достоверность содержания: непроверенные документы отмечены `not_manually_reviewed`, короткие страницы и возможные заглушки требуют проверки. Ошибки доступа сохранены отдельно от скачанных файлов.

## Подготовленные таблицы

- `kap_winter_2026_2027_segments.csv`: 72 строки сегментов и периодов действия из четырех таблиц официального зимнего расписания Камчатского авиапредприятия, 26.10.2026–26.03.2027. Объединенные ячейки раскрыты; сохранены рейс, начало и конец сегмента, местное время, тип ВС, дни недели и исключения по датам. Это не 72 уникальных маршрута. Текстовые расписания районных вертолетов и летнее расписание сохранены в полном HTML, но не включены в эту нормализованную таблицу.
- `hmrn_subsidy_2024_schedule.csv`: 4 отправления по двум направлениям Горноправдинск — Лугофилинская из задания конкурсного отбора перевозчика на субсидию. PDF стр. 18, печатная стр. 34, публикация 22.02.2024. Это требования конкурса, а не заключенный договор и не фактические рейсы. Указанные в источнике 264 рейса сохранены на уровне маршрута и не суммируются по четырем строкам; начало работы зависит от закрытия зимников.
- `tables/index.csv` и `tables/*.csv`: структурное извлечение HTML-таблиц, включая заголовки и справочные таблицы. Число строк здесь не равно числу транспортных связей; предметная проверка каждой таблицы не выполнена.

В конкурсном PDF часть кириллицы извлекается с постоянным смещением кодов символов. `derive.py` сохраняет отдельное восстановленное извлечение `*.pages.repaired.json`; исходный PDF и исходный текст не меняются. Страница с расписанием проверена визуально, изображение — `qa/hmrn-page18.png`.

## Воспроизведение и ограничения

Из корня: `python3 datasets/additional/transport-operations/acquire.py`, затем `python3 datasets/additional/transport-operations/derive.py`. Нужны requests, beautifulsoup4, lxml, pypdf, pandas. `--retry-transient` повторяет только тайм-ауты и HTTP 502/504. Уже учтенные URL по умолчанию пропускаются; для каждого нового ответа файл пишется заново через временный файл, смешивания версий при докачке нет. Ограничение одного источника — 30 MiB.

Полной федеральной базы расписаний и выполненных перевозок нет. Ключ Яндекс Расписаний в окружении отсутствует; API не выгружен. Сохранена документация API, а открытые сайты перевозчиков собраны отдельно. Расписание не измеряет отмены, заполняемость, фактическое ожидание или грузопоток. Большинство сайтов не указывают открытую лицензию повторного распространения; исходные файлы остаются локальными, авторство и адреса сохранены.
