RFSD и ФНС не следует складывать: это пересекающиеся источники о компаниях с различными методами подготовки. Выручка компаний не равна ВРП. У RFSD необходимо учитывать заполненные авторами пропуски и точность геокодирования. У ФНС ИНН начинается с кода налогового органа; это не достаточная географическая привязка текущей деятельности компании.

У RFSD 2025 есть одна строка с пустым ИНН; уникальных непустых ИНН — 3 143 177. Координаты описывают регистрацию организации: 2 265 750 записей имеют точность дома, 619 499 — улицы, 193 934 — города. Подготовлены 12 684 агрегата по региону, секции ОКВЭД и флагам источника. В RFSD финансовые суммы в тысячах рублей, в выгрузке ФНС — в рублях. Годы 2012–2024 не выдаются за полученную историческую панель: докачка остановлена, подтвержденные интервалы и отдельные `.partial` сохранены для явного возобновления.

Транспортные замеры относятся к конкретным датам и пиковым интервалам, а не к текущему трафику всей России. Расписание или конкурсное задание не подтверждает выполнение рейсов. Районные закрытия и статусы родительского маршрута сохранены отдельно от независимо наблюдавшихся состояний переправ.

Полная API-выгрузка Яндекс Расписаний требует отсутствующего ключа. Полный федеральный план северного завоза закрыт личным кабинетом. Часть транспортных сайтов возвращает ошибки или заглушки; все попытки сохранены. Архив новостей Югры также имеет зафиксированные пробелы HTTP 503. Эти ограничения не заменены синтетическими данными.

`python3 datasets/additional/verify.py` проверяет локальные файлы по сохраненным контрольным суммам и формирует `verification.json` и `local-files.csv`. Для журналов повторного получения проверяется последняя версия каждого пути. Незавершенные файлы исключаются из числа и объема полученных данных, их занятое место учитывается отдельно. Скрипты предметного извлечения и условия воспроизведения указаны в README каждого набора. Проверка архива подтверждает целостность файлов, а не полноту национального покрытия или истинность каждого утверждения источника.
