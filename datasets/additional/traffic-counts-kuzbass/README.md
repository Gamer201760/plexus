# Измеренная интенсивность движения на дорогах Кузбасса

Дополнительный источник, найденный при обсуждении экономической связанности. Не входит в первоначальные 38 строк каталога. География проекта командой не выбрана.

[Первичная страница Дирекции автодорог Кузбасса](https://kuzdor.ru/nasha-deyatelnost/soderzhanie-avtomobilnyh-dorog/otchet-ob-intensivnosti/). Исходный Excel сохранён в raw/, 45 числовых записей — в derived/traffic_counts.csv. Размеры, URL и SHA-256: [metadata.json](metadata.json), проверенная структура: [profile.json](profile.json).

Есть дорога, километр пункта, границы и длина перегона, классы транспорта, ТС/сутки, приведённые к легковому автомобилю единицы и максимумы интенсивности. Класс B включает автомобили и небольшие грузовики/фургоны; сумма класса C выделена как тяжёлые грузовые категории. Это количество транспортных средств, не тоннаж или число уникальных поездок.

Период требует уточнения: заголовок внутри говорит «за 2023 год» и одновременно «по состоянию на 01.01.2026»; сравнительная колонка также помечена 2023. Год наблюдений оставлен неопределённым, 2025 не присвоен по имени файла.

Для переноса на сеть нужны сопоставление дороги/километража, геометрия, направления и определения периода. Эти сечения не являются матрицей происхождения и назначения потоков и не связывают каждый груз с отраслью или ВРП. Вложения и потери ВРП по этим числам сами по себе не выводятся.

Дополнительный контроль: у 5 из 45 записей сумма опубликованных классов не совпала с опубликованным общим потоком. Оба числа и разность сохранены; автоматической правки не было. Такие строки требуют сверки перед калибровкой.
