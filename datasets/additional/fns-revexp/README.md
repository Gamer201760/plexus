# ФНС: доходы и расходы компаний за 2025 год

Полностью получена последняя национальная выгрузка, указанная на [странице ФНС](https://www.nalog.gov.ru/rn54/opendata/7707329152-revexp/) на 07.11.2026. Префикс `/rn54/` относится к региональному представлению сайта; сам набор охватывает Россию. [Исходный ZIP](https://file.nalog.ru/opendata/7707329152-revexp/data-20261025-structure-20180110.zip) опубликован 25.10.2026.

Исходники: `data/additional/fns-revexp/raw/`; производные: `data/additional/fns-revexp/derived/`.

- ZIP: 99 568 119 байт; SHA256 `947900d16af5fd549d8f076671976cd2e59422f2b0a9b9d20f48b3529d67e526` совпал с контрольной суммой в ответе издателя.
- Все 2 010 XML прочитаны до конца с проверкой CRC и синтаксиса XML. Несжатый объем — 733 106 895 байт; распаковывать весь архив на диск не потребовалось.
- `income_expense_2025.parquet`: **1 809 218 строк и уникальных ИНН**, дубликатов ИНН нет. Все записи относятся к 31.12.2025; документы сформированы 25.10.2026.
- ИНН сохранен строкой. Доходы и расходы — исходные суммы в рублях типа `decimal128(19,2)`, без заполнения пропусков. `document_id` и `source_member` сохраняют происхождение. Доход равен нулю в 361 618 записях, расход — в 267 203.

`СумДоход` — общий бухгалтерский доход, который нельзя молча подменять выручкой по строке 2110 из RFSD. Координат, отраслевого кода и расположения производственных площадок здесь нет. Связь по ИНН с RFSD дает географию регистрации юридического лица с флагами точности. Префикс ИНН не является достаточной географической привязкой предприятия.

ФНС ссылается на [типовые условия использования открытых данных](https://www.nalog.gov.ru/files/tipovye_usloviya_od.pdf): требуется указание источника и корректное представление данных, допускается коммерческое и некоммерческое использование. Лицензия Creative Commons не заявлена. Учетная запись или платный API не использовались.

Воспроизведение: Python 3 + PyArrow, `python3 datasets/additional/fns-revexp/profile.py`. Скрипт проверяет CRC, разбирает XML и пишет Parquet, профиль и реестр членов архива. Валидация по XSD не выполнялась. Для повторного скачивания используйте URL из `manifest.json`; файл следует проверять перед заменой.

Прямое скачивание страницы и PDF условий через shell вернуло HTTP 403; содержание и ссылки проверены веб-инструментом. ZIP и XSD скачаны успешно. Метаданные страницы сохранены как наблюденные сведения, а не выданы за оригинальный HTML.
